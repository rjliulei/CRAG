## 抽样目标（是否达标）

| 目标 | 要求 | 本子集 | 判定 |
|------|------|--------|------|
| 规模 | 100–200 | 200 | ✅ |
| 分层依据 | Vanilla×RAG 结果 + 题型 + 领域 | 脚本自动 | ✅ |
| 五领域 | 均覆盖、大致均衡 | 均有（见下表） | ✅ |
| 八题型 | 均覆盖；`false_premise` 不低于全量占比 | **29 / 200 = 14.5%**（全量 ≈11.4%） | ✅ |
| 结果类型 | correct / hallucination / missing 都有 | 都有 | ✅ |
| 硬例 | 双方幻觉、RAG 幻觉、RAG 更差等优先 | 硬例合计 **100 / 200 = 50%** | ✅ |
| 对照例 | 保留 RAG 救回、双方正确、双方 missing | 29 / 17 / 37 | ✅ |

**定位：** 「硬例偏多的快迭代集」，**不是**全量分数的缩影。子集上 hallucination 会明显高于全量 RAG（刻意抬高），**勿用子集分数直接外推全量**。

## 标签说明（重要）

1. **无裁判 dump ≈ missing**：exact-match 正确且未调裁判 API 的样本也会被记成 missing（量少）。
2. **Vanilla** 旧 dump 无 `sample_idx`，用 **query 文本**对齐；偶发对不齐则落到 missing。
3. 清单里的标签用于**分层与错误分析**，精细 case 研究时建议再核对原文与预测。
