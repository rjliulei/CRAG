## 0. 前置

| 项目 | 要求 |
|------|------|
| Python | 3.10 |
| GPU | 8B 基线 ≥16–24GB；对齐官方用 4×T4 |
| 账号 | Hugging Face、OpenAI API Key |
| 磁盘 | 数十～上百 GB |

## 1. 环境

```bash
cd /path/to/CRAG
python -m venv .venv
source .venv/bin/activate   # Windows: .\.venv\Scripts\Activate.ps1
pip install -U pip && pip install -r requirements.txt
```

Windows 上 vLLM 支持差，正式跑基线建议 Linux + CUDA。

## 2. 数据

默认路径：`example_data/dev_data.jsonl.bz2`  
下载 Task1/2：[crag_task_1_and_2_dev_v4.jsonl.bz2](https://github.com/facebookresearch/CRAG/raw/refs/heads/main/data/crag_task_1_and_2_dev_v4.jsonl.bz2?download=)  
Task3 见 [`docs/dataset.md`](../dataset.md)。

## 3. 权重

| 模型 | 路径 |
|------|------|
| Llama-3.1-8B-Instruct（本环境默认） | `models/meta-llama/Llama-3.1-8B-Instruct` |
| all-MiniLM-L6-v2（RAG） | `models/sentence-transformers/all-MiniLM-L6-v2` |

先接受 Llama 条款并 `hf auth login`，再按 [`download_baseline_model_weights.md`](../download_baseline_model_weights.md) 用 `hf download` 下载。

## 4. 按 GPU 改参数

| 参数 | 默认 | 单卡 24GB | 4×T4 |
|------|------|-----------|------|
| `VLLM_TENSOR_PARALLEL_SIZE` | 4 | **1** | 4 |
| `BATCH_SIZE` | 8 | 先 4 | 8 |
| `VLLM_GPU_MEMORY_UTILIZATION` | 0.85 | OOM 降 0.7 | 0.85 |

## 5. 选模型（`models/user_config.py`）

```python
from models.vanilla_llama_baseline import InstructModel
UserModel = InstructModel
# 或 DummyModel / RAGModel / RAG_KG_Model
```

## 6. Mock API（Task2/3 / RAG-KG）

```bash
cd mock_api && pip install -r requirements.txt
uvicorn server:app --host 127.0.0.1 --port 8000
export CRAG_MOCK_API_URL=http://localhost:8000
```

## 7. 评估 Key

```bash
export OPENAI_API_KEY=sk-...
export EVALUATION_MODEL_NAME=gpt-4-0125-preview   # 可选
```

## 8. 运行

```bash
python local_evaluation.py
```

建议先 DummyModel + 小样本冒烟，再上 Llama 全量。
