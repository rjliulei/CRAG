# Vanilla 与全量网页 RAG 结果对比

> 生成日期：2026-08-25  
> 对照实验：同数据 Task1/2 全量 v4（2706）、同裁判硅基流动 `deepseek-ai/DeepSeek-V3.2`、同生成模型 `Llama-3.1-8B-Instruct`。

## 结论

相对 **Vanilla 全量**，**网页 RAG 全量**答对更多、拒答更少，综合分由约 0 变为略正（**+0.014**）；但幻觉同步上升，提升有限。瓶颈从「不会答」转向「答得更猛、也更容易编」。

## 全量指标（① vs ③）

| 指标 | Vanilla ① | RAG ③ | 变化 |
|------|-----------|-------|------|
| **score** | **−0.00185 ≈ 0** | **+0.014** | **+0.016** |
| accuracy | 15.8%（427） | 23.1%（626） | **+7.5 pp（+199）** |
| hallucination | 16.0%（432） | 21.7%（588） | **+5.7 pp（+156）** |
| missing | 68.3%（1847） | 55.1%（1492） | **−13.2 pp（−355）** |

验算：

- Vanilla：`(2×427 + 1847) / 2706 − 1 = −0.00185`
- RAG：`(2×626 + 1492) / 2706 − 1 = +0.01404`

---

## 解读

1. **检索有效**：正确 427→626，拒答 68%→55%。
2. **score 仅略正**：多对 199、多幻觉 156，奖惩部分抵消。
3. **作答时正确率略升**：Vanilla 约 49.7%，RAG 约 51.6%（仅统计非 missing）。
4. **瓶颈**：missing↓、hallucination↑ → 宜做拒答/可信与降噪，而非只堆召回。
