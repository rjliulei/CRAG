# 01 · 硬件要求

> 整理日期：2026-08-20  
> 依据：本仓库基线代码 + KDD Cup 2024（CRAG）官方评测环境  
> **若你已确定用 AutoDL 24GB，日常操作请直接看 [03-AutoDL单卡24GB操作手册.md](./03-AutoDL单卡24GB操作手册.md)。**

## 官方评测环境（KDD Cup 2024）

| 项目 | 配置 |
|------|------|
| 云主机 | AWS `g4dn.12xlarge` |
| GPU | **4 × NVIDIA T4** |
| 单卡显存 | **16GB**（合计约 64GB） |

说明：
- 基线默认 `VLLM_TENSOR_PARALLEL_SIZE = 4`
- `dtype="half"`（fp16）；T4 **不支持 bfloat16**
- 70B 全精度无法直接跑，需量化
- T4 较旧，部分加速库可能不兼容

## 按场景建议

| 场景 | 建议 |
|------|------|
| 只跑 Mock API / 看数据 | CPU + Python 3.10 |
| 跑 Llama 3 8B 基线 | **1×24GB**（推荐）或官方 **4×16GB** |
| 70B | 需量化 |
| 磁盘 | 权重约十几 GB；Task 3 更大，预留数十～上百 GB |

## 当前选用方案

- **平台**：AutoDL  
- **配置**：1 × 24GB（推荐 RTX 4090）  
- **手册**：[03-AutoDL单卡24GB操作手册.md](./03-AutoDL单卡24GB操作手册.md)  
- **关键改动**：`VLLM_TENSOR_PARALLEL_SIZE = 1`，`BATCH_SIZE` 先设 4

## 可调参数位置

- `models/vanilla_llama_baseline.py`
- `models/rag_llama_baseline.py`
- `models/rag_knowledge_graph_baseline.py`

参数：`BATCH_SIZE` / `SUBMISSION_BATCH_SIZE`、`VLLM_TENSOR_PARALLEL_SIZE`、`VLLM_GPU_MEMORY_UTILIZATION`、`SENTENTENCE_TRANSFORMER_BATCH_SIZE`
