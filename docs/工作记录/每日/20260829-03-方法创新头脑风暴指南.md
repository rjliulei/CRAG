## 1. 先定调：什么叫「方法新」

| 不够新（避免当主贡献） | 可能够新（需实验支撑） |
|------------------------|------------------------|
| 调 top-k / 相对余弦阈值 | 针对本地失败模式的**新决策逻辑**（何时滤、缩、拒） |
| 单独上 MMR | **新信号**（如问题约束是否被片段满足），非答案–片段像不像 |
| Corrective RAG 原样 + Web 搜 | CRAG **无外网**约束下的纠检索变体，且判据与论文不同 |
| v2 事后答案相似度改 IDK | 主指标绑 **accuracy / rag_worse**，机制在**生成前** |
| 「我们做了拒答」 | 与 Sufficient Context / Self-RAG **差在哪**能一句话说清 |

**宜用的贡献句模板（会上填写）：**

> 在 CRAG 嘈杂网页设定下，针对 **〔失败模式/题型〕**，我们提出 **〔机制名称〕**：用 **〔新信号或新决策〕** 在生成前做 **〔滤噪/缩窗/拒答/约束生成〕**，使得 **〔accuracy↑ 或 rag_worse↓〕**，且不以 missing 暴涨为唯一手段。相对 Corrective/Astute/Sufficient Context，差别是 **〔一句〕**。

## 2. 现有实验能不能支撑头脑风暴？

### 2.1 已经够用的（当作风暴输入）

| 证据 | 含义（禁区 / 缺口） |
|------|---------------------|
| 全量 RAG：acc↑ 且 hall↑，score 仅微升 | 只加检索不够；要可信/降噪，不是换更大模型 alone |
| 200 子集错误结构：生成错 / 过度检索 / 缺证据 | 创新应对准其中 1–2 类，勿贪大 |
| `rag_worse`=25，几乎全是过度检索 | **高价值切片**：Vanilla 对、RAG 错 → 「检索致错」 |
| max_score 中位≈0.75；τ=0.30/0.40 几乎不触发 | **禁止**再把「绝对 query–chunk 余弦」当主创新 |
| v2：score↑、accuracy↓ | **禁止**把事后改 IDK 当主创新；可作负对照 |
| 假前提上 RAG 已偏会拒 | 假前提不是当前主幻觉源 |

### 2.2 还不够的（风暴后要用最小实验补）

- 任一「新方法」在 200 子集上的 before/after  
- 相对 Corrective-lite / 单纯 top-k 的消融  
- 全量 2706 泛化（有子集信号后再做）

**结论：** 数据**足够定义问题与禁区**，**不足以宣称新方法已成立**。风暴产出 = 可跑假设，不是论文标题。

## 4. 筛选标准（四条同时满足才进入候选）

打分：每条 0/1，满分 4；**≥3 才做**。

| # | 标准 | 说明 |
|---|------|------|
| S1 | **非旧件 alone** | 不是单独的 top-k / MMR / v2 答案相似度 |
| S2 | **贴本地桶或题型** | 能指出打 `rag_worse` / set+约束 / 生成错 等哪一块 |

- 主效果只来自 missing↑、accuracy↓ → **否决为主贡献**  
- 需要新训大模型 / 依赖稳定外网 API 才能成立 → **本阶段降级或推迟**

## 6. 启发用「新」类型（仅供打开思路，不是定稿）

会上可从下列类型各硬想 1 条，再丢进 §4 筛子：

| 类型 | 含义 | 贴本地的例子（可改） |
|------|------|----------------------|
| **决策新** | 滤噪/缩窗/拒答的**触发条件**与论文不同 | 按题型或「是否含可校验约束（年份、集合边界）」分支 |
| **信号新** | 不用答案比片段；用约束满足度、冲突、槽位覆盖等 | 「2017 之后」是否在候选句中可被支持/证伪 |
| **目标新** | 主报 `rag_worse` 恢复率或 set 题准确率 | 不只报整体 score |
| **组合接口新** | 轻量模块组合，但**接口判据**为错误分析定制 | 须写明哪一步是新的，否则仍算工程拼装 |
| **设定约束下的变体** | 无 Web 再检索、单卡 8B | 相对 Corrective 的 Incorrect→Web，你们改为？ |

**明确降级为对照、不当主创新：**

- 档 A 仅 top-k / 相对阈值（可作强基线）  
- v1 绝对阈值、v2 事后一致性
