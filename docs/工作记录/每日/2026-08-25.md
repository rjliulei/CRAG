# 2026-08-25 · Vanilla vs RAG 全量结果对比

## 结论（一句话）

相对 08-21/22 的 **Vanilla 全量**，最近这次 **网页 RAG 全量**（同 2706、同 DeepSeek 裁判）答对更多、拒答更少，综合分由约 0 变为略正（+0.014）；但幻觉同步上升，提升有限。瓶颈从「不会答」转向「答得更猛、也更容易编」。

## 解读

1. **检索确实有效**  
   正确数 427→626，拒答 68%→55%。模型更敢答，也更常答对。

2. **综合分只略正，因幻觉同步升高**  
   多对 199，多幻觉 156；奖惩部分抵消，score 仅从约 0 到 +0.014。

3. **真正开口作答时，正确率略升**  
   - Vanilla：427 / (427+432) ≈ **49.7%**  
   - RAG：626 / (626+588) ≈ **51.6%**  
   不完全是「乱答换正确」，仍有一点证据收益，但接近对半开。

4. **瓶颈变化**  
   missing↓、hallucination↑ → 网页噪声 + 弱过滤推高自信错误。与暂定方向「检索–生成–拒答/可信」对齐。
