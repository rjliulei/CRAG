## 全量对比（① vs ③，唯一公平对照）

| 指标 | Vanilla ① | RAG ③ | 变化 |
|------|-----------|-------|------|
| **score** | **−0.00185 ≈ 0** | **+0.014** | **+0.016** |
| accuracy | 15.8%（427） | 23.1%（626） | **+7.5 pp（+199 正确）** |
| hallucination | 16.0%（432） | 21.7%（588） | **+5.7 pp（+156 幻觉）** |
| missing | 68.3%（1847） | 55.1%（1492） | **−13.2 pp（少拒答 355）** |

验算：

- Vanilla：`(2×427 + 1847) / 2706 − 1 = −0.00185`
- RAG：`(2×626 + 1492) / 2706 − 1 = +0.01404`

---

## 解读

1. **检索确实有效**  
   正确数 427→626，拒答 68%→55%。模型更敢答，也更常答对。

2. **综合分只略正，因幻觉同步升高**  
   多对 199，多幻觉 156；奖惩部分抵消，score 仅从约 0 到 +0.014。

3. **真正开口作答时，正确率略升**  
   - Vanilla：427 / (427+432) ≈ **49.7%**  
   - RAG：626 / (626+588) ≈ **51.6%**  
   不完全是「乱答换正确」，仍有一点证据收益，但接近对半开。

4. **瓶颈变化**  
   missing↓、hallucination↑ → 网页噪声 + 弱过滤推高自信错误。与暂定方向「检索–生成–拒答/可信」对齐。
