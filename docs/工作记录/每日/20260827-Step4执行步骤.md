## 已知问题与修复（2026-08-28）

**现象**：`baseline` 与 `abstain τ=0.40` 四指标完全一致（逐条预测也相同），拒答门控未生效。

**原因**：`local_evaluation_deepseek.py` 在 `load_dotenv()` **之前** `import UserModel`，而 `rag_llama_baseline.py` 在 **模块 import 时**读取 `RAG_ABSTAIN_*`，`.env` 尚未载入。

**修复**（已合入）：

```python
# local_evaluation_deepseek.py / local_evaluation.py
if __name__ == "__main__":
    load_dotenv()                        # 必须先于 ↓
    from models.user_config import UserModel
```
