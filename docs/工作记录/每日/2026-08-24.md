## 今日主线：上机全量跑 RAG

**目标：** 与 Vanilla 同数据（约 2706）、同裁判（DeepSeek-V3.2），跑通网页 RAG，对比四指标。  
**手册：** [05-RAG与RAG-KG基线操作手册.md](../05-RAG与RAG-KG基线操作手册.md) §2。

### 清单

1. **确认 GPU 空闲** — `nvidia-smi`；停掉仍占显存的评测会话。
2. **下载 MiniLM（若无）** — `sentence-transformers/all-MiniLM-L6-v2` → `models/sentence-transformers/all-MiniLM-L6-v2/`。
3. **`.env` 切全量数据** — 与 Vanilla 同源；不要用 `dev_subset_100_*`。  
   例：`DATASET_PATH=/root/autodl-tmp/20260820-crag/crag_task_1_and_2_dev_v4.jsonl.bz2`（以服务器实际路径为准）。
4. **切换基线** — `models/user_config.py`：注释 `InstructModel`，启用 `RAGModel`（不启 Mock API）。
5. **tmux 评测**
   ```bash
   cd /root/autodl-tmp/CRAG
   source .venv/bin/activate
   unset OMP_NUM_THREADS
   mkdir -p logs
   python local_evaluation_deepseek.py 2>&1 | tee logs/eval_rag_$(date +%Y%m%d_%H%M%S).log
   ```
   OOM 时：`VLLM_GPU_MEMORY_UTILIZATION` → `0.70`～`0.75`，或减小 `SUBMISSION_BATCH_SIZE`。
6. **记录四指标** — `score` / `accuracy` / `hallucination` / `missing`，与 Vanilla 并排写入本文件「结果」节。
7. **之后** — 抽 100–200 典型子集；可选 RAG-KG。

### 判断标准

| 现象 | 含义 |
|---|---|
| RAG 的 score / accuracy 明显高于 Vanilla | 检索有效 → 可做切分 / 召回 / 重排 / 拒答 |
| 几乎不动或更差 | 先查检索是否生效、OOM、prompt / missing |
