## 0. 本轮硬禁区

任何人提起即否决，不得写入贡献句：

```text
RH-ACS / RH-ACS+ · 闭卷探针 a0 ·「检索伤害→回退闭卷」
约束覆盖充分性 · RHR/rag_worse 作主贡献叙事
「相对 Astute/Corrective 差一句」当卖点
top-k / MMR / v1 / v2 alone
```

**允许：** 用本地桶当现象输入（set 幻觉、simple 硬答、缺证据、生成错、HTML 噪声），机制不得走「闭卷通道选择」。

## 2. 拍板：5 个全新点（互不为父子）

### N1 · AFFR — Answer-Form First Retrieval

> 在 CRAG 短答设定下，先预测答案形态（单实体 / 集合 / 数值 / 时间 / 是非），再切换检索聚合与解码约束，使形态错配导致的幻觉下降。

| 项 | 内容 |
|----|------|
| 打哪 | simple 乱填实体；set 当叙述答 |
| ≠ | 不是 domain 题型路由；不是是否检索的门 |
| 最小实验 | 规则形态分类 + 两套 prompt/聚合；200 vs 固定 RAG |

### N2 · CBSD — Cardinality-Bounded Set Decoding

> 对 set 题在生成前估计答案基数 \(k\)，解码或后处理强制 \(|\hat{Y}|\le k\)（或 \(=k\)），专打名单膨胀。

| 项 | 内容 |
|----|------|
| 打哪 | Pixar 类多列（set 幻觉 21/29） |
| ≠ | 不是相关度阈值；不是闭卷回退 |
| 最小实验 | 仅 set 子集开关；看 set 幻觉 + 四指标 |
| **四方偏好** | E/S 最快主做；L 缺口清晰 |

### N3 · DSM — Dual-Source Membership Gate

> 集合/多实体答案中，每个候选成员须被 **≥2 条非近重复片段** 独立支持才写入；单源则丢弃该成员（非整题拒答）。

| 项 | 内容 |
|----|------|
| 打哪 | 多片段拼名单；both_hallucination 的 set |
| ≠ | 不是 ALCE 长文引用；不是题级充分性 |
| 最小实验 | 实体–片段对齐 + near-dup；set 切片主表 |
| 与 N2 | **正交**：N2 管长度，N3 管准入；可组合但叙事各立 |

### N4 · TAR — Temporal Anchor Pushdown

> 从问题解析时间锚，在切句过滤与排序中作为硬特征（过期句降权/剔除），再生成。

| 项 | 内容 |
|----|------|
| 打哪 | 带年份/「之后」约束题；过期娱乐页噪声 |
| ≠ | 不是答后约束检查；不是充分性分数 |
| 最小实验 | 日期解析 + 句级时间标签；时间题切片 + 全 200 |

### N5 · SKV — Structured KV Intermediate

> 将 top 页/句强制抽成「实体–属性–时间」键值表，LLM **只读表答题**；主消融「原文拼接 vs 表」。

| 项 | 内容 |
|----|------|
| 打哪 | HTML 噪声诱导的生成错；缺证据仍流畅编造 |
| ≠ | 不是通道选择；不是事后改 IDK |
| 最小实验 | 规则/LLM 短抽取 → 表 prompt；表征消融必做 |
