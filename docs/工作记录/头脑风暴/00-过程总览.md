## 3. 最终决议（摘自 08）

**方法名：** RH-ACS+（Retrieval-Harm-Aware Channel Selection）

**机制骨架：**

```text
算约束覆盖 c
  c 极低     → 拒答
  高风险题   → 短闭卷探针 a0
       与证据冲突 → 回退闭卷 a0   ★ 打 rag_worse
       否则       → RAG 生成
```

**补的缺口：** G1 相关≠不伤害 · G2 无 Web 回退闭卷 · G3 非余弦充分性 · G6 主看 rag_worse  

**明确不卖：** 纯 top-k、v1、v2、Corrective+Web、单独 M3/M5/M6  

**下一步：** `rag_llama_baseline.py` 实现 MVP → 200 子集四指标 + rag_worse 桶表
