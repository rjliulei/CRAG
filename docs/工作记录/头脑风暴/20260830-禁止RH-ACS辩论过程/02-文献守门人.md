# 02 · 文献守门人（禁止 RH-ACS 轮）

**任务：** 执法禁区；标易撞车；指出**空白地带**；否决禁区回潮点子。

---

## 1. 禁区执法

下列不得当本轮贡献：

- Retrieval Harm / 闭卷探针 / 通道选择（≈08 RH-ACS+）  
- 「我们补 G1/G2/G6」话术复读  
- Sufficient 式题级充分性换信号  

---

## 2. 易撞车 vs 空白

| 易撞车 | 空白地带（可挖） |
|--------|------------------|
| 题型路由、adaptive RAG | **答案形态/基数**作检索与解码目标 |
| NLI 忠实度、ALCE 引用 | **项级双源准入**（短答 set，非长文归因） |
| query rewrite | **时间锚下推到切句/排序**（CRAG 动态切片硬做） |
| HTML→text 常规清洗 | **强制 KV 表再生成**当主机制 + 表征消融 |
| contrastive decoding | 有文献；绑 CRAG 短答可做变体，但 **像连续闭卷门 → 本轮否决** |
