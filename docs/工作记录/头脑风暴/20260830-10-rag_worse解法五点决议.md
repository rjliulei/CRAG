## 2. 拍板：5 个 rag_worse 解法（互不为父子）

### W1 · RH-ACS+ — 通道级伤害路由

> 约束覆盖 **c** + 门控闭卷探针 **a0**；`c 高 ∧ a0–证据冲突 → 输出 a0`；否则 RAG；c 极低 → IDK。

| 项 | 内容 |
|----|------|
| 打哪 | 定义性 rag_worse：闭卷已对被绑架 |
| ≠ | 不是 Astute 融合；a0 是 harm 探针不是第二融合源 |
| 本周 | **主做 MVP**（门控闭卷） |

### W2 · ECP — 证据冲突剪枝（仍走 RAG）

> 生成前剔除违约束 / 与核片段互斥的 chunk；剪空则闭卷或 IDK。

| 项 | 内容 |
|----|------|
| 打哪 | 少数高分误导句绑架；少误伤 rag_helps |
| ≠ | 不是整题弃检索；不是只调相关分 |
| 本周 | **可先跑**（零额外生成） |

### W3 · CDR — 对比去检索解码

> 解码时减去「检索引入且无片段支撑」的 logits 偏置。

| 项 | 内容 |
|----|------|
| 打哪 | 已走 RAG 仍被 token 级带偏 |
| ≠ | 不是生成前路由；不是事后改 IDK |
| 本周 | **No-Go**（改生成循环险） |

### W4 · AVC — 闭卷对照验真（答后）

> RAG 答后槽级：被 a0 否证且无片段支撑 → 删槽或回退 a0。

| 项 | 内容 |
|----|------|
| 打哪 | a0 对但 RAG 膨胀实体/名单 |
| ≠ | 不是 v2 余弦相似度刷分 |
| 本周 | 二期；可与 W1 共享 a0 |

### W5 · SCC — 单一致簇生成

> top-k 按槽赋值聚类，**只喂一簇**，禁止跨页并集。

| 项 | 内容 |
|----|------|
| 打哪 | 多片段各说各话 → 并集幻觉（Pixar 类） |
| ≠ | 不是 N2 基数约束主叙事；可不依赖 a0 |
| 本周 | set 切片可选插件 |
