## 1. 常见误解

> 「检索结果是错的，模型不可能答对 —— 这无解。」

这句话只在下面的设定成立：

> **只准根据这份错误检索作答，且禁止回退闭卷、禁止拒答。**

`rag_worse` 和「检索本身是错的」要解的，恰恰是：**不要逼模型根据错证据硬答。**

---

## 2. 情况 A：`rag_worse`（约 25/200）

### 2.1 它是什么

| | Vanilla（不用网页） | RAG（用了网页） |
|--|---------------------|-----------------|
| 结果 | **答对** | **幻觉** |

含义：参数知识（闭卷）**本来就能对**；加上检索后被高分噪声/误导片段**带偏**。  
不是「没证据所以无解」，而是 **「检索绑架了本已会的题」**。

### 2.2 怎么处理（按优先级）

| 策略 | 做法 | 期望 |
|------|------|------|
| **① 回退闭卷** | 判定检索不可靠或高伤害 → **不用网页**，按 Vanilla 通道答 | 最直接恢复正确（对准 rag_worse） |
| **② 滤噪后再答** | 去掉冲突/不满足约束的句，再生成 | 少被带偏；有时仍可用好句 |
| **③ 拒答** | `I don't know` | 避免幻觉；acc 未必升，score 可能改善 |

**主路径建议：** ① 或 ②（要 **accuracy↑ / rag_worse↓**）；③ 作保底，不作唯一手段。

### 2.3 在线如何判断「检索在害人」（不看标准答案）

- 拟采用的检索答案与 top 片段对不上 / 问题约束对不上 → 不信检索稿  
- 相关分虽高，但年份/名单等**约束冲突** → 缩窗或丢弃  
- （更强）同时有闭卷草稿：检索稿相对闭卷大改且证据弱 → **采用闭卷**

## 3. 情况 B：检索结果本身是错的 / 没用的

| 子类 | 含义 | 怎么办 |
|------|------|--------|
| **B1 噪声、跑题** | 和问题「像」，但帮不上忙 | 生成前过滤、缩 top-k、相对阈值、约束过滤 |
| **B2 误导、冲突** | 错事实、多页说法打架 | 冲突检测；禁止乱合并列表；必要时拒答 |
| **B3 整页都没用** | 没有可支撑的证据 | **不硬答**：拒答，或闭卷会则回退 Vanilla |
| **B4 只有外网能救** | 库内检索全错 | Corrective 会 Web；本赛道常 **不能乱搜** → 拒答/闭卷 |

**原则：**  
「检索错了」≠ 必须从错检索里挖出正确答案。  
正确动作：**识别不可用 → 换通道（闭卷）/ 清证据（滤噪）/ 弃权（拒答）**。

---

## 4. 统一决策骨架（可当方法接口）

```text
检索 top-k
  → 证据是否可用？（约束 / 冲突 / 相关三态）
       ├─ 可用且干净     → 用检索生成
       ├─ 半可用         → 滤噪 / 缩窗后再生成
       ├─ 不可用或高伤害风险
       │     ├─ 闭卷可能有解（双通道）→ 回退 Vanilla
       │     └─ 否则                 → I don't know
       └─ 禁止：明知检索烂仍塞满 top-20 硬编
```

## 5. 和目标、创新叙事的对应

| 担心 | 处理结论 |
|------|----------|
| rag_worse 无解？ | **有解**：解除检索绑架（回退闭卷 / 滤噪），不是从坏检索炼真理 |
| 检索本身是错的？ | **先判定再动作**：滤 / 缩 / 回退 / 拒，不硬答 |
| 只靠错检索答对？ | 一般做不到，**也不该当研究目标** |

对 [05](./20260829-05-高创新与补缺口-下午头脑风暴.md) 缺口的落点：

| Gap | 本文对应动作 |
|-----|----------------|
| G1 相关≠不伤害 | 伤害风险判定 → 回退/滤噪 |
| G2 Incorrect 不 Web | 回退闭卷或拒答，不换源硬答 |
| G6 以 rag_worse 为主目标 | 成功线含「检索致错桶恢复」 |
| G7 避免只靠事后改 IDK | 决策在**生成前 / 通道选择**，拒答是支路不是主刷分器 |

---

## 6. 一句话

**检索错了，就不要逼模型根据错证据答对；要么清证据，要么改用闭卷，要么拒答。`rag_worse` 说明第三条之外还有「闭卷这条路」——无解的是「只准看错检索还要答对」，有解的是「别被错检索绑架」。**
