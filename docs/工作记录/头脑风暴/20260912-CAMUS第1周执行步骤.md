## Step 1 · 读懂插入点（约 15 分钟，不改代码）

打开 `models/rag_llama_baseline.py` 的 `batch_generate_answer`，找到类似逻辑：

1. 算 `cosine_scores`（query–chunk）  
2. `argsort` 取 `[:NUM_CONTEXT_SENTENCES]`（默认 20）  
3. 拼进 prompt → 生成  

**CAMUS 要插在：** 已有全部候选句 + cosine 之后，**最终截断进 prompt 之前**。  
也就是：先让 CAMUS 从候选里选出子集 \(E^*\)，再把 \(E^*\) 当「上下文句子」往下走。

## Step 3 · 最小选证逻辑（MVP，可先糙）

按决议伪代码实现「贪婪加句」——**先做前两项，Harm 可第二刀再加**：

1. **解析约束（糙即可）**  
   - 从问题里抽：专有名词 / 年份 / 是否像 set 题（含 list、which of、movies 等启发式）  
2. **CovGain**  
   - 某句是否新覆盖了某个约束词/年份（规则匹配即可，不必上 NLI）  
3. **冗余**  
   - 与已选句子的最大 cosine；太高则扣分  
4. **（可选本步）HarmProxy**  
   - 高 cosine 但 CovGain=0；或 set 题且像名单罗列 → 扣分  
5. 循环：`argmax ΔU`，若 `ΔU ≤ ε` 或满 budget 则停  

公式提醒：

```text
ΔU ≈ CovGain − λ·冗余 − γ·Harm
```

**红线：** 选证不得读标准答案、评测标签、该题历史对错。

勾选：

- [x] `_camus_select` 真正按 ΔU 选，而不只是截 top-k  
- [x] 可对单题打印：选中了哪几句、每句 ΔU（`RAG_CAMUS_DEBUG=1`）

**已落地（2026-09-13）：**

| 组件 | 行为 |
|------|------|
| `_camus_parse_constraints` | 实体（去问句引导词）、`after/before YEAR`→`year>/year<`、set 启发式 |
| CovGain | 相对已选集合，新覆盖约束原子数 |
| 冗余 | 与已选句 embedding 最大余弦（调用处传入 `relevant_chunks_embeddings`） |
| Harm | 高 query-cos 且 gain=0；set 题名单诱导（多逗号 / including…） |
| 贪婪循环 | `argmax ΔU`，`ΔU≤ε` 早停；候选池 top-`RAG_CAMUS_POOL`（默认 40） |
| 空选兜底 | 若第一轮全 ≤ε，回退 top-1 cosine，避免空 references |
| 调试 | `.env`：`RAG_CAMUS_DEBUG=1` 打印 atoms / 每句 ΔU |

> 单测示意：问「Pixar movies after 2017」时，优先选「2019 + Pixar」句，而不是仅主题相似或名单诱导句；约束盖满后可早停（不必凑满 budget）。

参考：[06-最终研究决策 · CAMUS Algorithm](./20260830-证据效用头脑风暴过程/06-最终研究决策.md)

## Step 9 · Go / No-Go（本周结束时必须拍板）

| 现象 | 判定 | 下一步 |
|------|------|--------|
| worse 有明显 H→C，acc≥baseline，helps 的 C→W≈0 | **Go** | 进入第 2 周：消融 + SAFE-U |
| 与 top-8/MMR 几乎无差 | **复查** | 查是否退化成小 k；加强约束/Harm；可选 HOPS |
| helps 大崩，或只涨 missing | **谨慎** | 收 γ/ε；或改开 **W1**（另写贡献，见 10 决议） |
| 完全无效 / 实现明显有 bug | **修代码** | 不要急着换方法 |
