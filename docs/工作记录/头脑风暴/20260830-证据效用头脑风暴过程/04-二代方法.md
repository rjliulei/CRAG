## G2-1 · CAMUS — Constraint-Aware Marginal Utility Selection

**杂交**：C（约束支持 S） + D（ΔU 贪婪） + B（set-level / 预算） + A（F2/F3 taxonomy）

### 核心

不再最大化 \(\mathrm{sim}(q,e)\)，而贪婪最大化边际约束效用：

\[
\Delta \widehat{U}(e\mid E,q)
=
\underbrace{\mathrm{CovGain}(e\mid E,q)}_{\text{新覆盖的约束原子}}
-\lambda\,\mathrm{Redund}(e,E)
-\gamma\,\mathrm{HarmProxy}(e,q)
\]

\[
E \leftarrow E\cup\{e\} \iff \Delta\widehat{U}>\varepsilon;\quad
\text{否则停止（最小充分近似）}
\]

**HarmProxy（training-free）**：高 cosine ∧ 低约束覆盖；或 list-inducement ∧ set 题；或同槽多值冲突。

### 与余弦本质区别

排序键是 **边际约束贡献−害**，不是相似度；停止规则由 ΔU 决定，不是固定 k。

### 融合了谁

| 来源 | 吸收 |
|------|------|
| C4 / C-R2-1 | CovGain / S |
| D1 | ΔU 贪婪停止 |
| B-R2-1 | set 目标 |
| A1/A3 | 缺槽、交互害 |

### 风险

代理 U 退化成 coverage−MMR → 创新分下降；必须用 D4 实验证明「比熵减 IG 更贴 rag_worse」。

## G2-2 · HOPS — Harm-Oriented Pruning for Set-interaction

**杂交**：A（F3/F7/F8） + D3（负信息） + B-R2-2（交互边，简化） + C5（槽矩阵）

### 核心

不追求「选最优充分集」的完整优化，而专攻 **集合交互伤害**：

1. 建轻量槽矩阵 slot×chunk  
2. 同槽多赋值 → 冲突边；近重复 → 冗余边  
3. set/list 题：限制「列表诱导句」配额  
4. 剪掉 harm 边端点中 **约束贡献更低** 的一侧  
5. 输出仍走 RAG（不回退闭卷）

### 与 W2 ECP 关系

同属「生成前剪枝」；HOPS 显式 **set-interaction + harm**，不是一般冲突。可与 CAMUS 叠：HOPS 预剪 → CAMUS 贪婪。

### 风险

被说成冲突检测工程；需 set 切片显著性和 case。

## G2-3 · SAFE-U — Supportive ≠ Entropy Utility（差界方法+主张）

**杂交**：D4（IG≠正确） + C-R2-1（S） + E1（可学习校准，可选） + G（强制对照实验设计）

### 核心

**方法贡献的一半是科学主张**：在嘈杂网页 RAG、尤其 `rag_worse` 上，

\[
\mathrm{IG}(e)=H(\mathrm{tokens}\mid q)-H(\mathrm{tokens}\mid q,e)
\]

与

\[
U_{\mathrm{acc}}(e)=\mathbb{E}[\mathbf{1}\{\hat{a}(q,E\cup e)\ \mathrm{correct}\}]
\]

**可负相关**（F6：有害自信）。

操作化：同一候选池分别用 IG 排序与 Constraint-ΔU 排序；主表报 worse 流转。

### 为何算「方法」不是纯分析

给出可运行的双轨选择器 + 明确选用 \(U_{\mathrm{acc}}\)-proxy 的决策准则；不是只写 blog。

### 风险

若两者差不多，主张失败（仍有负结果价值，但发表变难）。

## G2-4 · MSES — Minimum Sufficient Evidence Search（预算化）

**杂交**：B4/B-R2 MSE + C2 nec/suf + A5 防稀释 + D-R2 bottleneck

### 核心

\[
E^*=\arg\min_{E\subseteq C}|E|
\quad\mathrm{s.t.}\quad \mathrm{Cov}(E,q)\ge\tau
\]

无「最大相关」；在满足覆盖后 **停止添加**。Cov 不足则保留「最佳努力」小集或交由拒答策略（拒答不是本方法主卖点）。

### 与 CAMUS 区别

CAMUS 连续打 ΔU（含 harm）；MSES 先满足覆盖再最小化基数——更偏 MSE 经典形。

### 风险

τ 调参；Cov 假高 → 过早停止。

## G2-5 · QAP — Question-Adaptive Evidence Policy（约束结构路由）

**杂交**：C-R2-2 + E3 MoE 思想（规则版） + A 题型易损表 + B3（降级为策略表）

### 核心

路由键 = **约束结构**（非 domain 标签）：

| 结构 | 策略 |
|------|------|
| set/list | 配额 + HOPS 预剪 + 较小 B |
| temporal | 时间硬过滤 + CAMUS |
| numeric/compare | 冲突边优先 |
| simple factoid | MSE 更小 B，防稀释保留 top-Cov |

### 风险

Adaptive-RAG 撞车；必须强调「约束结构→选择准则」差界，并消融「仅改 k」。

---

## G2-6 · RNL-Struct — Structural Retrieval-Negative Features（防泄漏版）

**杂交**：E-R2-1 + A taxonomy 特征化 + D3 Harm + F 的泄漏约束

### 核心

离线从 **训练划分** 的 Vanilla✓RAG✗ 总结 **结构特征**（非实体黑名单）：

- 高 sim、低 CovGain  
- 同槽冲突密度  
- 列表诱导比例  
- 跨页实体并集宽度  

训浅层 harm 分类器；推理只跑特征。  
**硬规则**：测试 200 若含训练样本 → 必须 group split 或只做分析不训。

### 风险

n 小；审稿人默认怀疑 leakage；本周不宜作 Top1。
