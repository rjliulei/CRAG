## 2. 六法创新等级

| Method | Level | 理由 |
|--------|------:|------|
| **CAMUS** | **2–3** | 组件多来自 coverage/MMR/harm 启发式；**若**坚持 U≠IG 且有 worse 桶实证 + 清晰目标式，可到 **3** |
| **HOPS** | **2** | set 交互剪枝；像强化版冲突/配额；单立偏工程，作 CAMUS 前置可接受 |
| **SAFE-U** | **3（主张）/2（系统）** | 「IG 与正确性可脱钩」在 IGP 流行时有审查价值；系统本身是双轨对照 |
| **MSES** | **2** | 最小充分集已被 Context-Picker/CER/多篇讨论；training-free Cov 版更像工程 |
| **QAP** | **1–2** | 易落 Adaptive 换皮；除非约束结构路由有强消融 |
| **RNL-Struct** | **2–3** | 失败驱动 harm 有故事；n 小+泄漏风险拉低可发表性 |

**无 Level 4。** 诚实结论：本轮最可能的发表点是  
**「在嘈杂网页 RAG 上，把证据选择目标从 similarity / entropy-IG 转为 constraint-marginal answer utility，并用 rag_worse 桶验证」**，  
而不是发明全新数学对象。

## 4. 对「ΔU formulation 是否值得做核心」的正反辩论

### 正方（D + B + Chair 部分）

- 唯一同时解释：相关但无用、冗余（ΔU≈0）、有害（ΔU<0）、停止条件（最小充分）。  
- 与本地失败机制（F1–F8）同构。  
- 插入点干净：cosine 后、format 前。  
- 可接学习版（ROM）而不改问题定义。

### 反方（F + 文献）

- **不可观**：无 GT 时任何 U 都是代理 → 易被打成 MMR+coverage。  
- **文献拥挤**：IGP 已占「utility=信息增益」；Influence selection / Context-Picker 占 set utility。  
- **估计成本**：真反事实 LOO 竞赛不可用。  
- **可能假创新**：写漂亮公式，实现仍是规则打分。

### 裁决（Chair）

**值得作为问题表述核心，但不值得宣称「发明了 ΔU」。**  

可发表的窄门是：

```text
Answer-Utility（约束边际 / 正确性代理）
        ≠
Relevance
        ≠
Entropy Information Gain
```

在 **CRAG 噪声网页 + rag_worse** 设定下给出证据，并给出 **training-free CAMUS** 作为可复现实例。

若 48h 内 Constraint-ΔU **不能**在 worse 流转上打过 top-k/MMR/（可选）IG 代理，则 **降级**：ΔU 只保留为分析框架，主做 HOPS 或回到轨 A W1。
