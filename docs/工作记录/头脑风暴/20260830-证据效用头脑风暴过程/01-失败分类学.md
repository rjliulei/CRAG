## 1. Failure Taxonomy（一级：按机制）

### F1 · Topic-Similar Non-Support（主题相似但不支持）

- **定义**：chunk 与 query 共享实体/主题词，余弦高，但不携带回答所需的约束绑定信息。  
- **例**：问「2017 之后 Pixar 电影」，句「Toy Story 4 is a Pixar film」——实体对、约束未证成。  
- **与 relevance 关系**：relevance↑，support 缺席或不全。  
- **单句 vs 集合**：单句即可误导；多句同型会放大「汇总冲动」。

### F2 · Partial Constraint Match（部分约束命中）

- **定义**：满足实体或关系之一，但缺时间 / 数值 / 集合完整性 / 比较端。  
- **例**：有「Pixar + 电影名」，无「上映年 ≥ 2017」或与题口径不一致。  
- **危险性**：模型把「部分支持」当成「全支持」。

### F3 · Over-Retrieval Aggregation（过度检索并集）

- **定义**：多网页、多句各自相关，模型做 **并集/拼名单**，超出 GT 口径或真实充分集。  
- **例**：Pixar 类 set；Green Day 成员类 both_hallucination 亦有类似。  
- **集合效应**：单句可能都不「假」，**组合**产生错误答案形态。

### F4 · Redundant Echo（冗余回声）

- **定义**：近重复或同槽多份表述占满 top-20，挤占互补证据位，并强化错误主导叙事。  
- **机制**：baseline 仅字符串 `set` 去重，近义复述仍大量进入。

### F5 · Conflictive / Competing Slots（冲突槽）

- **定义**：不同 chunk 对同一槽给不同赋值（日期、人数、成员）。  
- **模型行为**：挑「看起来更完整/更自信」的一侧，或折中编造。

### F6 · Distractor Confidence Boost（噪声提置信）

- **定义**：噪声使生成分布更尖、更敢答，但指向错误实体/名单。  
- **对「熵减=有用」的否证**：不确定度下降 **不等于** 正确性上升（见后文与 IGP 差界）。

### F7 · Format / List Inducement（格式诱导）

- **定义**：检索文是片单、目录、推荐列表 → 诱导模型输出过长枚举。  
- **与题型**：set / list 题受害最大。

### F8 · Cross-Page Composition Hallucination（跨页合成）

- **定义**：A 页供实体₁，B 页供实体₂，模型合成「完整答案」但无单源充分支持。  
- **集合效应纯正例**：point-wise 可能都「相关」。

### F9 · Temporal / Numerical Drift（时空数值漂移）

- **定义**：过期页、错误年份、近似数字进入高分区。  
- **cosine 盲点**：时间约束是符号/逻辑，不是嵌入几何。

### F10 · Helpful-Evidence Dilution（有用证据稀释）

- **定义**：真正支持句存在于候选中，但被 15–19 条噪声淹没；4000 字符截断可能切掉后部真证据。  
- **rag_helps 风险**：乱砍 top-k 会误伤本类。

## 2. 二级：按问题类型的易损性

| 题型 | 主导失败型 | 为何易受 over-retrieval 伤害 |
|------|------------|------------------------------|
| **set / list** | F3, F7, F8 | 模型默认「多列更全」；网页片单直接提供模板 |
| **带时间约束** | F2, F9 | 年份是硬约束；嵌入只抓主题 |
| **数值 / 比较** | F2, F5 | 近似数、冲突数难靠 cosine 分辨 |
| **多条件 factoid** | F2, F10 | 需同时覆盖多约束；并集易引入无关实体 |
| **simple 短答** | F1, F6 | 高分闲聊句即可替换正确短答 |
| **false_premise** | （次要） | 本子集非主战场；过度检索仍可能硬答 |

## 3. Relevance ↔ Usefulness 脱钩：机制图

```text
Query q
  │
  ▼
MiniLM cosine ──► 高分 chunk 池（主题/实体共现）
  │
  ├─ Supportive? ──否──► F1/F2（看起来相关，不能支撑完整答案）
  │
  ├─ Alone OK, Set bad? ──是──► F3/F7/F8（集合交互伤害）
  │
  ├─ Δ confidence ↑ but answer wrong? ──是──► F6（harmful）
  │
  └─ True support buried? ──是──► F10（稀释）
```

**单句噪声 vs evidence-set interaction**

| | 单句噪声 | Set interaction |
|--|----------|-----------------|
| 可检测性 | 可用约束覆盖 / NLI 近似 | 需看组合覆盖、冲突、冗余、诱导格式 |
| 对 U 的含义 | \(U(e,q)\) 低或负 | \(U(E,q) \neq \sum U(e_i,q)\) |
| 本地案例 | 单句 TS4 | 多页片单并集 |

## 4. `rag_worse` 产生路径（机制叙事，非算法）

```text
Vanilla: 参数知识或保守短答 → 正确
     +
HTML 噪声页 → 句切 → cosine top-20（分数整体偏高）
     +
F1–F8 混合进入 context
     ↓
LLM 被「相关且具体」的网页叙事绑架
     ↓
正确 → 幻觉（尤其 set 膨胀）
```

**不是**：检索完全失败（空结果）。  
**是**：检索「成功找到很多像相关的东西」，utility 为负或集合为负。

## 5. 对后续 Agent 的约束（Agent A 不提算法，只提问题）

后续方法必须能解释并干预至少一类：

1. **点式**：高 cosine 但低 support / 负 utility  
2. **集合式**：单点尚可、组合有害  
3. **题型条件**：set / 时间约束优先  
4. **保护**：不能把 F10（真证据）切掉导致 `rag_helps` 崩

**禁止**把「调 k / 调 τ」当作对 taxonomy 的解答。

---

## 6. 一句话

**`rag_worse` 的根因不是「不够相关」，而是「相关度排序把主题相似、部分约束、冗余回声与跨页并集送进了生成器」；失败在 utility 与 set interaction，不在 cosine 数值本身。**
