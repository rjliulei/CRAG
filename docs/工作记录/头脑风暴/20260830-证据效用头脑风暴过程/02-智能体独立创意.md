# Agent A · Failure Mechanism Scientist（机制 → 可检验方向）

> A 的「方法」必须由 taxonomy 导出；不追求工程完备。

### A1 · Partial-Support Detector（部分支持检测）

1. **核心观察**：高分句常只覆盖实体，不覆盖时间/集合约束（F2）。  
2. **baseline 失败**：cosine 把部分支持当全支持。  
3. **机制**：解析 query 约束槽；句级打「覆盖哪些槽」；缺关键槽则降权/剔除。  
4. **≠ cosine**：目标是 constraint coverage，不是相似度。  
5. **输入**：q, candidates, scores。6. **输出**：过滤/重排后的 E。  
7. **pipeline**：cosine top-N → 约束覆盖过滤 → format。  
8. **训练**：可 training-free（规则）或轻量分类。9. **label**：规则无需；若训，用合成「缺槽句」。  
10. **LLM**：可选。11. **额外模型**：可选小 NLI。12. **成本**：低–中。  
13. **rag_worse**：砍掉 TS4 类缺年句。14. **误伤 rag_helps**：改写句、代词句被误杀。  
15. **可证伪**：时间/set 切片改善，但 simple 无约束题不变或变差。  
16. **最小实验**：规则年份+实体覆盖，仅 set/时间题开。  
17. **风险**：像「关键词过滤」工程。18. **接近**：constraint filtering / NLI support。19. **创新性**：低–中（taxonomy 驱动差界）。

### A2 · Aggregation-Inducement Score（并集诱导分）

1. 观察：片单/目录格式诱导 set 膨胀（F7）。  
2. 失败：top-20 塞满列表句。  
3. 机制：检测 list-like 表面形式；对 set 题限制「列表句」配额。  
4. ≠ cosine：惩罚格式诱导，非相关度。  
5–7. 输入候选；输出配额后的 E；插在 top-N 后。  
8–12. training-free；无 LLM；低成本。  
13–14. 压 set 幻觉；可能误伤「答案本身在列表中」的 helps。  
15. set 幻觉↓且 simple 不变则成立。16. 仅 set 切片。17. 规则脆。18. 格式启发式。19. 低。

### A3 · Set-Interaction Failure Probe（集合交互探针）

1. 观察：\(U(E)\neq\sum U(e_i)\)（F3/F8）。  
2. 失败：point-wise top-k。  
3. 机制：对候选做小规模 leave-one-out / 成对共现惩罚（同槽多值）。  
4. ≠ cosine：显式交互项。  
5–7. 候选集 → 交互图/惩罚 → 子集。  
8. 可无训。10. 可选短 LLM。12. 中。  
13. 专打并集。14. 互补多跳被当成冲突。15. 多源 set 改善、单源不变。16. 同槽多值去重实验。17. 与冲突检测撞车。18. diversity/conflict。19. 中。

### A4 · Confidence-Harm Correlation Study → Proxy（F6 代理）

1. 观察：噪声可提高错误置信。  
2. 失败：把「具体细节多」当好证据。  
3. 机制：用「细节密度×约束缺口」作 harm proxy，降权。  
4. ≠ cosine。8. free。12. 低。  
13. 压敢答幻觉。14. 细节丰富的真证据被压。15. 细节↓则幻觉↓但 missing↑则假说偏。16. 代理消融。17. proxy 弱。18. 启发式。19. 低–中（机制有启发）。

### A5 · Dilution-Aware Retention（防稀释保留）

1. 观察：F10 真证据被淹没。  
2. 失败：一刀切 top-5。  
3. 机制：在压缩时强制保留「最大约束覆盖增量」的句，而非最高 cosine。  
4. ≠ cosine：边际覆盖。8. free。12. 低。  
13. 间接：少噪声。14. 若覆盖估计错会伤 helps。15. helps 保持 + worse 降。16. vs top-5。17. 像 MMR+coverage。18. submodular cover。19. 中（作组件）。

### A-R2-1 · Evidence Harmfulness Label Taxonomy（远距离 · Harm）

主动定义 **harmful evidence**：相关∧（事实可真）∧加入后期望答错↑；用 rag_worse 离线分析模式，**推理禁用 GT**。  
创新点在「害」的操作化定义，而非过滤器本身。

### A-R2-2 · Minimum Diagnostic Context（远距离 · MSE）

研究问题：回答 q 的 **最小充分诊断集** 大小分布；证明 over-retrieval 伤害与 |E| 相关。  
产出是科学主张 + 上界实验，可驱动后续选择器。

# Agent B · IR Researcher

### B1 · Listwise Utility Ranking

1. 观察：pointwise cosine 忽略列表位置交互。  
2. 失败：独立打分。  
3. 机制：listwise 模型对 top-N 输出排列，目标贴近「生成正确」伪标签。  
4. ≠ cosine：list 目标。8. 需训。9. 离线：用 train 上 with/without 子集正确性作弱标（禁 test GT）。10. 可选。12. 中–高。  
13. 重排掉有害位。14. 分布外题型崩。15. listwise≫pointwise 在 worse 桶。16. 小 listwise vs CE。17. 数据泄漏/弱标噪声。18. listwise rerank。19. 低–中。

### B2 · Submodular Coverage Selection

1. 观察：需要覆盖约束元素，非堆相似。  
2. 机制：\(f(E)=\mathrm{Cover}(E)-\lambda\mathrm{Redund}(E)\) 贪婪。  
4. ≠ cosine：集合目标。8. free。12. 低。  
13. 少冗余多覆盖。14. Cover 定义错则伤。15. |E|↓且 acc≥baseline。16. vs MMR。17. 像 MMR。18. submodular IR。19. 低（对照强）。

### B3 · Adaptive Retrieval Budget by Query Entropy

1. 观察：factoid 需极少证据，set 需受控配额。  
3. 机制：题型/不确定性 → 动态 k 与停止规则。  
4. ≠ 固定 top-20。8. free/轻量分类。12. 低。  
13. 降 over-retrieve。14. 题型分错。15. 分题型 k* 不同。16. 规则题型路由。17. Adaptive-RAG 撞车。18. adaptive retrieval。19. 低。

### B4 · Information Bottleneck Context

1. 观察：多而相关劣于少而够用。  
3. 机制：最大化 \(I(E;A^*)-\beta I(E;X)\) 的可计算代理（无 A* 时用约束覆盖代理）。  
4. ≠ top-k。8. free 代理 / 或训。12. 中。  
13. 压噪声。14. 代理≠真 IB。15. 更短 context + 不降 acc。16. 长度–acc 曲线。17. 理论空转。18. IB / compression。19. 中。

### B5 · Requirement Decomposition Retrieval

1. 观察：复合问题需分需求检索再合并。  
3. 机制：分解子需求 → 每需求取 1–2 句 → 合并去冗余。  
4. ≠ 单 query 向量。8. free/LLM 分解。12. 中。  
13. 减少跑题句。14. 分解错。15. 多约束题↑。16. 规则分解。17. query decomposition 旧。18. multi-query。19. 低–中。

### B-R2-1 · Set-level Argmax U(E,q)（远距离 · Set）

显式 \(E^*=\arg\max_{E\subseteq C,|E|\le B} U(E,q)\)；U 含 support/coverage/redundancy/conflict/harm。  
用贪婪或 ILP/QUBO 近似。与「排序截断」范式决裂。

### B-R2-2 · Evidence Interaction Graph Selection（远距离 · Graph）

边类型：support / duplicate / contradict / complement；选最大一致且覆盖约束的子图。  
专打 F5/F8。

# Agent C · Reasoning & Evidence Scientist

### C1 · Entailment-to-Constraints（约束蕴含）

1. 观察：support ≠ topical overlap。  
3. 机制：q→约束原子；e ⊨ atom? 用 NLI/规则。  
4. ≠ cosine。8. free+可选 NLI。12. 中。  
13. 滤非蕴含。14. NLI 假阴。15. 约束题↑。16. 小 NLI。17. NLI filter 旧。18. NLI rerank。19. 低。

### C2 · Necessary vs Sufficient Evidence Tags

1. 观察：有的句必要非充分，有的充分。  
3. 机制：标记 nec/suf/irrelevant；优先组「充分小集」。  
4. ≠ 相关排序。8. 需定义启发式或训。12. 中。  
13. MSE。14. 标签不稳。15. |E|↓ acc≥。16. 人工 25 条校准启发式。17. 主观。18. sufficient subset。19. 中。

### C3 · Temporal Anchor Hard Filter

1. 观察：F9。3. 时间锚下推到过滤。4. ≠ cosine。8. free。12. 低。  
13. 时间题。14. 无显式日期句。15. 时间切片。16. 同 N4。17. 工程。18. temporal IR。19. 低（已有 N4）。

### C4 · Partial Support Penalty

1. 观察：部分支持最危险。  
3. `score = cov_frac - γ·(1-cov_frac)·sim`：高相似低覆盖更罚。  
4. 显式惩罚「像但不全」。8. free。12. 低。  
13. 专打 F2。14. 多跳部分句。15. worse↓ helps 不崩。16. 惩罚项消融。17. 像加权关键词。18. coverage scoring。19. **中（差界清晰）**。

### C5 · Claim-Slot Fill Matrix

1. 观察：答案是槽填充。  
3. 建 slot×chunk 支持矩阵，只保留能填 ≥1 未填槽的 chunk。  
4. ≠ 全局相似。8. free。12. 低–中。  
13. 停冗余。14. 槽设计错。15. set 膨胀↓。16. 矩阵可视化 case。17. 像 DSM/N3。18. slot filling。19. 中。

### C-R2-1 · Supportive Evidence Score S(e,q)（远距离 · Utility）

定义 \(S(e,q)=P(\text{constraints of }q\text{ satisfied}|e)\)，显式替代 \(R=\mathrm{sim}\)。  
可学习校准，但推理无 GT。

### C-R2-2 · Constraint-Aware Retrieval Policy（远距离 · Constraint）

按约束类型切换选择准则（时间硬过滤 / set 配额 / factoid MSE）。  
与纯题型路由不同：路由键是 **约束结构**。

# Agent D · Information Theory / Causal Scientist

### D1 · Marginal Utility Greedy（ΔU）

1. 观察：应看 \(ΔU=U(E∪{e},q)-U(E,q)\)。  
3. 贪婪：每次加入 ΔU 最大且 >0 的 e；ΔU≈0 停；ΔU<0 永不加入。  
4. ≠ 固定 top-k。8. U 需代理。12. 视代理。  
13. 冗余与有害可同框架。14. 代理偏差。15. 选中集更短且 worse↓。16. 代理=覆盖增益。17. **估计 U 是核心难题**。18. submodular / IGP。19. **高（若 U≠熵）**。

### D2 · Counterfactual Leave-One-Out Screening

1. 观察：删掉 e 后答案是否变。  
3. 对 top-m 做廉价反事实（短解码或 logit 探针），估计影响。  
4. ≠ 相关分。8. free。10. 要 LLM 前向。12. **高**。  
13. 找关键有害句。14. 成本；不稳定。15. 去掉「高影响有害」后好转。16. 仅 25 条 LOO 诊断。17. 算力。18. influence / LOO。19. 中–高（诊断强，产品弱）。

### D3 · Negative Information Detector

1. 观察：存在负信息。  
3. 预测 \(H(e,q)=P(\text{answer worsens}|e)\)。  
4. 目标是 harm 不是 relevance。8. 需弱监督。9. **仅用 train/历史 rag_worse 模式**，禁 test。12. 中。  
13. 直接对准 worse。14. 过拟合模式。15. harm 分高的句被删后 worse→correct。16. 离线 AUC。17. leakage 指控。18. retrieval negative。19. 中–高。

### D4 · Conditional Information Gain ≠ Entropy Caution

1. 观察：熵减可能来自有害自信（F6）。  
3. 主张：**正确性效用** 与 **不确定度下降** 分离；若用 IG，必须加正确性代理或约束满足。  
4. 对 IGP 类方法的理论修正。8. 概念+实验。12. 低（实验）。  
13. 解释为何纯 IG 可能害 worse。14. 难测。15. IG 与 correctness 相关弱/负。16. 在 25 条上算 IG vs 对错。17. 负结果也有价值。18. IGP。19. **高（差界论文点）**。

### D5 · Causal Intervention View of Context

1. 观察：把 e 视为 do(context+=e)。  
3. 用简化因果图：e → answer tokens → correctness；选对 correctness 有正因果效应的 e。  
4. ≠ 相关。8. 需效应估计器。12. 高。  
13. 原则正确。14. 不可识别。15. 干预估计与真实 LOO 一致。16. 小规模。17. 空谈。18. causal NLP。19. 中（需落地估计器）。

### D-R2-1 · Counterfactual Retrieval Policy（远距离 · CF）

推理时比较 with-e / without-e 的短答一致性与约束满足，决定去留（预算受限版 D2）。

### D-R2-2 · Evidence Bottleneck with Harm Regularizer（远距离 · Bottleneck）

\(\max U_{\mathrm{correct}}(E,q)-\beta|E|-\gamma H(E,q)\)：显式害正则，不只压长度。

# Agent E · ML Method Inventor

### E1 · Weakly Supervised Utility Scorer

1. 观察：可用非 GT 弱标近似 U。  
3. 小模型打 \(û(e,q)\)；弱标：约束覆盖、与闭卷短答一致性（**注意**：闭卷一致性≠Astute 融合；此处只作训练特征/标，推理可不用闭卷）。  
4. ≠ cosine。8. 训。9. 弱标来自启发式+可选自洽。12. 中。  
13. 学到有害模式。14. 弱标偏。15. û 与 oracle LOO 相关。16. 小 MLP on features。17. 像 reranker。18. learned rerank。19. 中。

### E2 · Pairwise Preference over Evidence

1. 观察：相对「e1≻e2 for q」比绝对分稳。  
3. 对比学习：正=高覆盖低冗余，负=高相似低覆盖。  
8. 训。9. 合成对。12. 中。  
13. 重排。14. 合成分布偏。15. pairwise≫cosine。16. 对比头。17. 数据。18. preference learning。19. 中。

### E3 · Question-Type Conditioned MoE Selector

1. 观察：不同题型不同伤害。  
3. 门控专家：set/time/factoid 不同选择头。  
8. 训。9. 题型伪标。12. 中。  
13. set 专杀。14. 门控错。15. 分桶提升。16. 两专家。17. Adaptive-RAG。18. MoE policy。19. 低–中。

### E4 · Retrieval Outcome Model（ROM）

1. 观察：预测「加入 E 后是否答对」比预测相关。  
3. \(P(\mathrm{correct}|q,E)\) 小模型；选使该概率最大的 E（beam/greedy）。  
8. 训。9. **只用训练集**生成 outcome；可用 Vanilla/RAG 历史，禁 test outcome。12. 中–高。  
13. 直接优化终点。14. outcome 模型不准→乱选。15. ROM 选择 ≃ oracle 子集。16. 冻结合法 outcome 上界。17. 泄漏审查。18. outcome model / contextual bandit。19. **中–高**。

### E5 · Dynamic Context Budget Policy

1. 观察：预算应随 U 停止。  
3. RL 或启发式：停于边际 U<ε。  
8. 可 free。12. 低–中。  
13. 少喂。14. 早停丢证据。15. 自适应长度曲线。16. ε 扫描。17. 像早停。18. adaptive k。19. 低。

### E-R2-1 · Retrieval Negative Learning from rag_worse Patterns（远距离 · NegLearn）

用 **离线** Vanilla✓ RAG✗ 的检索模式学 harm 特征；部署时只跑特征→harm 分，**不读 GT**。  
必须报告：训练切分、是否与 200 测试重叠。

### E-R2-2 · Self-Supervised Counterfactual Utility（远距离 · Utility）

无 GT：对同一 q 采样子集 E_a, E_b，用生成器自洽/约束满足差作相对 U 标签。  
风险：自洽强化错误自信 → 必须与 D4 联用。
