## 详细攻击卡（选录）

### Idea: D1 Marginal Utility Greedy · Reviewer: F（Adversarial）

- **A. 最大优点**：把「加/不加」写成 ΔU，同时解释冗余（≈0）与有害（<0），对齐 rag_worse。  
- **B. 最大理论漏洞**：没有 GT 时 U 不可观；任何代理都可能把问题退化为 MMR/coverage。  
- **C. 最大实验漏洞**：若不设「U=正确性代理」对照「U=熵减」，会被审稿人指为 IGP 复刻。  
- **D. 重合**：submodular selection；IGP（2026）；Context-Picker / CER（最小充分集）。  
- **E. engineering trick?**：若代理=覆盖−冗余，是。若代理含 harm 且有实证差界，否。  
- **F. leakage?**：代理若用 test 对错 → 是；规则覆盖 → 否。  
- **G. missing 刷分?**：ΔU≤0 全丢 → 变拒答/空上下文；必须监控 acc 与 helps。  
- **H. 保留?**：**是（核心）**。  
- **I. 加强**：U := ConstraintGain − λRedund − γHarmProxy；**禁止**纯 NU/entropy；+ D4 对照实验。

### Idea: D1 · Reviewer: G（Experimental）

- **A.** 可写清 ablation：pointwise vs greedy ΔU vs oracle LOO 上界。  
- **B.** 上界实验：若 oracle ΔU（用 GT）也救不了 ≥8/25，则机制假说错，别训模型。  
- **C.** 200 子集小，要桶级流转表，不能只报总分。  
- **D–G.** 同 F。  
- **H.** 保留。  
- **I.** 先 48h **training-free 代理 ΔU**，再谈 ROM。

### Idea: E4 ROM · Reviewer: F

- **A.** 目标与任务终点对齐。  
- **B.** \(P(\mathrm{correct}|q,E)\) 在网页噪声下极难；模型可能学到「短上下文更安全」→ missing↑。  
- **C.** 训练 outcome 若来自同一 200 测试 → 直接死刑。  
- **D.** contextual bandit / outcome-driven retrieval。  
- **E.** 若只是学 top-k 偏好，是。  
- **F.** **高 leakage 风险**。  
- **G.** 高。  
- **H.** 二期；MVP 不做。  
- **I.** 换独立 split；先报告 outcome 模型校准曲线。

### Idea: E-R2-1 NegLearn · Reviewer: F

- **A.** 直接挖 rag_worse 模式，故事硬。  
- **B.** n=25 模式学习必过拟合；「Toy Story/片单」规则会伪装成学习。  
- **C.** 若不 leave-one-group-out，全是 test leakage。  
- **D.** hard negative / failure-driven training。  
- **E.** 很容易。  
- **F.** **默认怀疑有**。  
- **H.** 仅当严格切分+特征可解释时保留。  
- **I.** 特征必须是结构型（缺槽、列表配额、跨页同槽），禁止实体黑名单。

### Idea: C4 Partial Support Penalty · Reviewer: B

- **D.** coverage-based retrieval。  
- **E.** 偏工程，但可作 ΔU 代理组件。  
- **H.** 保留为 **组件**，不单立主方法。
