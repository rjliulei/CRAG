# Top1 · CAMUS

## 1. Research Hypothesis

> 在固定 MiniLM top-N 候选上，按 **约束边际效用** \(\Delta\widehat{U}\) 贪婪选证据（并在 \(\Delta\widehat{U}\le\varepsilon\) 停止），相对固定 top-k / MMR，能把更多 `rag_worse` 从 hallucination 转为 correct，且不显著增加 `rag_helps` 的 correct→wrong。

## 2. Key Innovation

**新在目标函数与停止规则**：选择键是「对当前已选集合的约束覆盖增益 − 冗余 − 有害代理」，不是相似度，也不是熵减；显式允许 \(\Delta\widehat{U}<0\) 的 evidence 永不进入 context。

## 3. Mathematical Formulation

约束原子集 \(\mathcal{C}(q)=\{c_1,\ldots,c_m\}\)（实体、时间、关系、集合需求等）。

\[
\mathrm{Cov}(E,q)=\sum_{c\in\mathcal{C}(q)}\mathbf{1}[\exists e\in E:\ e\ \mathrm{supports}\ c]
\]

\[
\Delta\widehat{U}(e\mid E,q)
=\mathrm{Cov}(E\cup\{e\},q)-\mathrm{Cov}(E,q)
-\lambda\,\mathrm{sim}_{\cos}(e,E_{\mathrm{max}})
-\gamma\,\mathrm{HarmProxy}(e,q)
\]

\[
\mathrm{HarmProxy}(e,q)=
\alpha_1\cdot\mathbf{1}[\mathrm{sim}(q,e)>\tau_s \wedge \mathrm{CovGain}=0]
+\alpha_2\cdot\mathbf{1}[\mathrm{ListInduc}(e)\wedge \mathrm{IsSet}(q)]
+\alpha_3\cdot\mathrm{SlotConflict}(e,E)
\]

\[
E^*\leftarrow\text{GreedyAdd}(\Delta\widehat{U}>\varepsilon),\quad |E^*|\le B
\]

## 4. Algorithm（伪代码）

```text
Input: q, candidates C with cosine scores, budget B, ε, λ, γ
Parse constraints C(q)
E ← ∅
while |E| < B:
  for e in C \ E:
    score[e] ← ΔU_hat(e | E, q)
  e* ← argmax score
  if score[e*] ≤ ε: break
  E ← E ∪ {e*}
return E
```

## 5. Pipeline

```text
MiniLM retrieval (top-N, N≥20)
        ↓
   [CAMUS]
        ↓
format_prompts
        ↓
generation
```

## 6. Training Requirement

**training-free**（MVP）。二期可用弱监督校准 γ/α，仍禁止 test GT。

## 7. Leakage Check

推理只用：query 文本、chunk 文本、cosine、规则约束解析。  
不用：标准答案、评测标签、该题历史对错。

## 8. 48-hour MVP

| 小时 | 动作 |
|------|------|
| 0–4 | 在 `batch_generate_answer` cosine 排序后插入钩子；env：`RAG_CAMUS=1` |
| 4–12 | 规则：实体/年份抽取；CovGain；近邻冗余；set 列表启发式 harm |

```text

```

## 10. Evaluation

主：accuracy / n_correct  
辅：score / hallucination / missing  
桶：rag_worse / rag_helps 流转：

```text
worse:  H→C | H→M | H→H
helps:  C→C | C→W | C→M
```

## 11. Prediction

- **若假设对**：worse 中 H→C ≥ 若干；acc≥baseline；helps 的 C→W 接近 0。  
- **若假设错**：与 top-8/MMR 无差，或 helps 崩、或仅 missing↑。

> We propose CAMUS: constraint-aware marginal utility selection that stops at approximate minimum sufficient evidence and down-weights harmful patterns.

# Top2 · SAFE-U

## 1. Research Hypothesis

> 在同一候选池上，按 **token 不确定度信息增益（IG）** 选证据，在 `rag_worse` 桶上的救助效果 **不优于**（甚至劣于）按 **约束边际效用** 选择——因为有害证据可降低熵却提高错误自信。

## 2. Key Innovation

把「效用」操作化为两个对立排序器并强制对照；贡献是 **目标函数差界**，不是又一个剪枝器。

## 3. Formulation

\[
\mathrm{IG}(e)=NU(q)-NU(q,e)
\quad\text{（实现可用短前缀 logprob；受 vLLM 限制则用简化探针）}
\]

对比 \(\Delta\widehat{U}\) 排序；报告与正确性的相关及桶流转。

## 4–5. Algorithm / Pipeline

与 CAMUS 同插入点；增加 `RAG_SELECT_MODE=ig|camus|cosine`。

## 6. Training

training-free。

## 7. Leakage

IG 计算不使用 GT；若算力不足用「细节密度」作 **假 IG 探针**必须标注 limitation。

## 8. 48h MVP

优先在 **离线诊断**（可多前向）对 25 条算：IG 排序 vs CAMUS vs cosine 的假想子集，再决定是否上线 IG 模式。

## 9–11. Ablation / Eval / Prediction

消融：三种排序 × 同一 B。  
若 IG 在 worse 上更好 → 我们的「F6」假说弱，改叙事。  
若 IG 更差或相关为负 → SAFE-U 主张成立，支撑 CAMUS。

## 12. Publication Story

> Recent work equates evidence utility with generator uncertainty reduction.  
> We show on retrieval-harm cases that uncertainty reduction can track harmful confidence.  
> Constraint-marginal utility better targets answer correctness under noisy web context.

# Top3 · HOPS

## 1. Research Hypothesis

> 专对 set/list 题，剪除「同槽多值 / 列表诱导 / 近重复」交互伤害后，名单膨胀型 `rag_worse` 下降，且不必回退闭卷。

## 2. Key Innovation

把 failure taxonomy 的 **集合交互** 做成生成前剪枝目标（仍输出 RAG context），而非点式相关过滤。

## 3. Formulation

槽矩阵 \(M_{s,e}\)；冲突密度；列表诱导指示；剪枝后 \(\tilde{C}\) 再进 top-k 或 CAMUS。

## 4–8. 算法与 MVP

规则实现；`RAG_HOPS=1`；先 set 切片再全量。零额外模型。  
泄漏：无。风险：纯工程观感 → 作 CAMUS 模块写进论文，或短文/技术报告。

## 9–12.

消融：无 HOPS / only HOPS / HOPS+CAMUS。  
预期：set 幻觉↓；simple 近似不变。  
故事：Over-retrieval harms via set interaction; HOPS prunes interaction edges before generation.

## 12. 为什么选它，而不是另外两个？

| 对比 | 理由 |
|------|------|
| vs SAFE-U | SAFE-U 是 **主张+对照**； alone 不构成完整系统贡献。CAMUS 是可上线的选择算法，SAFE-U 证明为何选这把刀。 |
| vs HOPS | HOPS 专打 set 交互，覆盖面窄，创新等级偏低；适合模块，不适合单独扛「方法章节」。 |
| vs MSES/QAP/RNL | 更易被换皮质疑，或泄漏/调参风险更高。 |
| vs 轨 A W1 RH-ACS+ | W1 有效但对准 **通道回退**，且 Astute 撞车叙事重；**本提示词插入点**要求主攻生成前「给模型看什么」。两轨可后续 ensemble，但本轮首选 CAMUS。 |
