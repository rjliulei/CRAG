## 拍板一句话（展开说明）

> **口令：** CAMUS 主做；SAFE-U 差界；HOPS 快刀；W1 并行不混叙事。  
> 这是「本周怎么排工作、怎么写贡献」的压缩说法，不是四个并列主方法。详拍板见 [06-最终研究决策.md](./06-最终研究决策.md)。

### 这句话在说什么？

四段各管一件事：**谁当主方法 / 对照怎么防撞车 / 什么可以先砍一刀验证 / 另一条线怎么并存且别写进同一贡献句**。

```text
你真正要卖的方法 ──► CAMUS（主做）
用来证明「不是熵减换皮」──► SAFE-U（差界 / 对照）
可选、更快的预剪 ──────► HOPS（快刀）
另一条通道线（回退闭卷）─► W1（并行，叙事分开）
```

---

### 1. CAMUS 主做

| 项 | 白话 |
|----|------|
| **是什么** | 生成前选证据：按「约束边际效用」\(\Delta U\) 贪婪加入片段——覆盖问题约束的增益 − 冗余 − 有害代理；增益不够就停，不是固定 top-20。 |
| **打哪** | 高分但有害/部分约束/名单诱导等「过度检索」；目标是让更多 `rag_worse` 从幻觉变对，且尽量不误伤 `rag_helps`。 |
| **主做指什么** | **默认把时间和实验预算花在它上面**：改代码钩子、跑 200 子集、做消融、写预实验结论。其它三项都是服务或旁路。 |
| **不是什么** | 不是拒答阈值（v1），不是答后一致性刷分（v2），也不是「要不要用检索」的通道开关（那是 W1）。 |

**落地默认：** 在 cosine 检索之后插入 CAMUS；对照 baseline top-20 / top-k / MMR；看 `rag_worse` 流转表。步骤见 06 文档「48-hour MVP」。

---

### 2. SAFE-U 差界

| 项 | 白话 |
|----|------|
| **是什么** | 同一候选池上，再跑一套按 **信息增益 / 熵减（IG）** 选证据的排序，和 CAMUS 的 \(\Delta U\) **硬对照**。 |
| **差界指什么** | 科学主张要钉死：**答对效用 ≠ 相关度 cosine ≠ 熵减 IG**。若 IG 选证在 `rag_worse` 上并不更好（甚至更差），就能挡住「你不就是 IGP / 熵减换皮」的审稿攻击。 |
| **不是什么** | **不是第二个主产品**，也不是本周第一优先实现；它是 **必做对照 + 叙事边界**。 |
| **何时做** | CAMUS MVP 跑通、有初步数字之后，再上 IG 对照；没有对照就难写清「新在目标函数」。 |

一句话：**SAFE-U 是用来证明 CAMUS「新在效用定义」的对照实验，不是另开一条主线产品。**

---

### 3. HOPS 快刀

| 项 | 白话 |
|----|------|
| **是什么** | 生成前剪掉「集合交互伤害」类片段（同槽冲突、列表/名单诱导等），仍走 RAG。 |
| **快刀指什么** | **实现轻、可先单独开关验证**；也可作为 CAMUS 的前置过滤器。先看 set 题幻觉能不能降。 |
| **不是什么** | 不当论文主创新故事（容易被说成工程冲突剪枝）；创新叙事仍归 CAMUS / SAFE-U。 |
| **何时做** | 想快速摸 set 失败模式，或 CAMUS 里 harm 项需要现成规则时，可先做；不替代 CAMUS 主实验。 |

一句话：**HOPS = 便宜的一刀，验证现象或给 CAMUS 喂 cleaner 候选；别把它写成主贡献。**

---

### 4. W1 并行不混叙事

| 项 | 白话 |
|----|------|
| **是什么** | 线 A / [10 决议](../20260830-10-rag_worse解法五点决议.md) 的 W1（RH-ACS+）：探测「检索在伤害闭卷已会的答案」→ **回退闭卷**（或极低覆盖则拒答）。机制底稿见 [08](../20260830-08-多智能体头脑风暴决议.md)。 |
| **并行指什么** | 可以和 CAMUS **同时存在、甚至同周各做一个 MVP**；两者解决的卡点不同，不互相废掉。 |
| **不混叙事指什么** | 汇报/开题/论文里 **不要写成「一个方法既选证据又回退闭卷」糊成一团**。贡献句分开：CAMUS 讲「选哪些证据」；W1 讲「要不要用检索这条通道」。 |
| **和 CAMUS 差在哪** | 见下表。 |

| | **CAMUS（线 C）** | **W1（线 A）** |
|--|-------------------|----------------|
| 管什么 | **哪些**片段进 context | **要不要**用检索（通道） |
| 典型动作 | 贪婪选证 / 早停 | 伤害高 → 输出闭卷答案 |
| 贡献关键词 | 约束边际效用、ΔU≠sim≠IG | 检索伤害路由、回退闭卷 |
| 本周默认 | **主做** | **并行备选**（主线卡住或要打定义性绑架时可上） |

一句话：**W1 可以做，但和 CAMUS 是两条贡献线；主线先讲 CAMUS。**

---

### 读完口令后你该做什么

1. **先做** CAMUS 在典型 200 上的最小钩子 + 对照表（见 [06](./06-最终研究决策.md) § CAMUS / 48h MVP）。  
2. **有数字后** 再上 SAFE-U（IG 对照），把差界写进结果讨论。  
3. **可选** 用 HOPS 先砍 set，或并进 CAMUS 的 HarmProxy。  
4. **需要打「闭卷本会对却被检索绑架」** 时再开 W1，叙事单独成段，不并进 CAMUS 贡献句。
