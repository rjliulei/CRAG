# 05 · 交叉辩论与拍板（rag_worse 解法轮）

四路对齐后，主持收束。本轮目标是 **专打 rag_worse 的解法主五**，不是 09 的换刀线。

---

## Round A · 问题是否钉死？

| 角色 | 立场 |
|------|------|
| 错误分析官 | 钉死：25 条 Vanilla✓→RAG✗；高分绑架，非分低该拒 |
| 文献守门人 | 同意；禁止逃回 N1–N5 当主解 |
| 方法 / 工程 | 同意：合法动作 = 回退闭卷 / 滤噪 / 拒答保底 |

**收束：** 本轮问题 = **解除检索绑架**；成功线必须含 **25 条流转**。

---

## Round B · 主做是否仍是 RH-ACS+？

| 角色 | 立场 |
|------|------|
| 错误分析 / 方法 | **是** — 定义性对准闭卷已对 |
| 文献 | **有条件是** — 六条 Astute 差界 + Astute-lite 强基线，否则换皮 |
| 工程 | **Go MVP**；效果不保证 |

**收束：** **主做 W1 RH-ACS+**；不是「再打磨措辞」，而是 **本轮解法空间里贴桶最强的一条**，同时并列挖出正交备选。

---

## Round C · 另外四条算不算「新解法」？

**争点：** 用户要的是解法头脑风暴，不是只交 RH-ACS 一票。

**收束：** 主五保留正交五轴：

| ID | 轴 | 动作 |
|----|-----|------|
| W1 | 通道 | 伤害→回退闭卷 |
| W2 | 输入 | 冲突剪枝后仍 RAG |
| W3 | logits | 对比去偏（工程本周否） |
| W4 | 输出 | 槽级闭卷对照验真 |
| W5 | 证据结构 | 单一致簇，禁并集 |

与 09 的 N1–N5 **问题不同**：此处每条必须回答「如何降 rag_worse」。

---

## Round D · 先滤噪还是先闭卷？

| 角色 | 立场 |
|------|------|
| 工程 | **先 B（W2）零成本**，再上 A（W1） |
| 错误分析 | 滤噪 alone 对 Pixar 式常不够；主叙事仍要回退 |
| 文献 | 滤噪是辅路；无回退不得宣称主贡献 |

**收束：** **实验顺序** 先 B 后 A；**论文主贡献** 仍钉 W1（或 W1+W2 双栏），B 作消融/对照。

**收束：** **并入 W1 升级路径**（a0 单探针不够 → 加 aR 增益验证）；不占主五第六席，避免与 W1 父子改名。

---

## 最终拍板（rag_worse 解法主五）

| ID | 名称 | 一句话 | 本周 |
|----|------|--------|------|
| **W1** | RH-ACS+ | 约束覆盖 + a0 冲突 → 回退闭卷 | **主做 MVP** |
| **W2** | ECP | 生成前冲突/约束剪枝，默认仍 RAG | **先跑验证** |
| **W3** | CDR | 解码期对比去检索偏置 | **No-Go** |
| **W4** | AVC | RAG 答后槽级 vs a0 验真/回退 | 二期或叠 W1 |
| **W5** | SCC | 单一致簇喂入，禁跨页并集 | set 切片可选 |

**只做一件打 rag_worse → W1。**  
**组合 → W1+W2。**  
**成功线 → ≥8/25 恢复 + acc 不降 + 流转表。**
