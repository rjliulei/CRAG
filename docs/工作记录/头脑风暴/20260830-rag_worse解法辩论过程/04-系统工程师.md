## 2. 显著 rag_worse↓ 能否保证？

**不能。** 工程只能保证：开关可跑、四指标表、25 条流转表、≥2 消融。  
a0 质量、槽抽取脆、门控漏判/误伤 rag_helps —— 效果用桶数据说话，不写进承诺。

## 3. 推荐落地顺序（验证绑架是否可解）

```text
D1     锁 RAG baseline 复现（200）
D1–2   B：约束/互斥剪枝（零额外生成）→ 看 25 条是否动
D2–3   若 B 不够 → A：RH-ACS+ 门控闭卷 MVP
D4     smoke 10 + 必要时 batch=2
D5     A full 200 + 25 条流转表初稿
D6     消融：去 a0 / 去约束（或仅 B vs A）
D7     定稿流转表 + 对照是否达方法成功线
（二期）C/G 升级反事实；F 仅 set 切片；D 明确不做
```

**原则：** 先证明「清证据」有没有用，再上「回退闭卷」——两者都是合法解法，但成本与撞车叙事不同。
