## 1. rag_worse 现象再钉死

在典型 200 子集中，`rag_worse_hallucination` **固定 25 条**：同一题 **Vanilla（闭卷）答对**，加上 top-k 网页 RAG 后 **变成幻觉**；Phase B 细标 25/25 均为「过度检索」，不是缺证据拒答类。诊断显示这些题的 **max 余弦分并不低**（子集样本多在 0.62–0.76，中位≈0.75），v1 阈值门几乎不触发——失败模式是 **「高分但误导的片段绑架了本已可用的参数知识」**，而非「检索分太低所以该拒」。典型如 Pixar「2017 年后电影」set 题：闭卷能答对，RAG 被含 Toy Story 4 等噪声页带偏，GT 不含 TS4。

**解法空间已澄清：** 目标不是从错检索里炼出正确答案；而是 **在线识别「检索在害人」→ 回退闭卷 / 滤噪后再答 / 拒答保底**。闭卷通道在这 25 条上已被 Vanilla 跑通，故主路径应优先 **恢复闭卷正确**，而非整题 IDK。

## 3. 专打 rag_worse 的方法假说（≥5）

> 均要求：**生成前或通道级**决策；**不看 gold**；**无 Web**；**无训练**。

### H1 · RH-ACS+（检索伤害感知通道选择）— 保留候选

| 项 | 内容 |
|----|------|
| **机制一句话** | 算问题约束覆盖 **c**；对高风险题生成短闭卷探针 **a0**；**c 高且 a0 与证据槽冲突 → 回退闭卷**；c 极低 → 拒答；否则 RAG。 |
| **为何能降 rag_worse** | 25 条本质是「闭卷已对、检索带偏」；a0 提供 **在线可得的闭卷锚**，冲突即 harm 信号，直接切回 Vanilla 通道。 |
| **需要什么信号** | 规则槽（年份/实体/集合类型）→ c；短闭卷 a0；top-k 对 a0 关键槽的支持/冲突（span/关键词/数值）。 |
| **风险** | 双倍生成成本；a0 本身错时误坚持闭卷；Astute 撞车叙事；门控过宽则 a0 覆盖不足。 |

---

### H2 · Counterfactual Gain Gate（反事实增益门，CFG）

| 项 | 内容 |
|----|------|
| **机制一句话** | 同题先出闭卷短答 **a0**，再出 **仅基于检索的短答 aR**；**仅当 aR 相对 a0 的「增量」被 top 证据显式支撑** 才走 RAG 全文，否则 **输出 a0**。 |
| **为何能降 rag_worse** | 直接操作 rag_worse 定义：Vanilla 对 = a0 方向已对；RAG 错 = aR 被噪声带偏；门控拒绝 **无证据支撑的偏离**。 |
| **需要什么信号** | a0、aR（均可限长）；增量槽 Δ = aR \ a0；top-k 对 Δ 的 span/NLI-lite 支持度。 |
| **风险** | 三次短生成延迟；a0、aR 都错时无救；与 RH-ACS+ 共享「闭卷探针」族，差界须强调 **「增益验证」而非「冲突即回退」**。 |

---

### H3 · Constraint-Predicate Evidence Pruning（约束谓词证据剪枝，CPEP）

| 项 | 内容 |
|----|------|
| **机制一句话** | 从 query **下推约束谓词**（如 `year>2017`、`member_of(set)`）；生成前 **丢弃/不喂** 不满足谓词的高分 chunk，仅对幸存句做 RAG。 |
| **为何能降 rag_worse** | Pixar 等 rag_worse 典型：**相似度高但违反集合/年份边界**；剪掉谓词违例句可阻断绑架，且闭卷知识无需被噪声列表覆盖。 |
| **需要什么信号** | 规则/轻量解析的约束槽；chunk 内年份、实体、比较词；谓词满足布尔。 |
| **风险** | 约束抽取错 → 误杀真证据；改写句无显式年份；**无 a0** 时剪完仍可能 hallucinate；对 simple 非约束 rag_worse 覆盖弱。 |

---

### H4 · Cross-Chunk Mutual Exclusion Gate（跨片段互斥门，CMXG）

| 项 | 内容 |
|----|------|
| **机制一句话** | 在 top-k 中检测 **关键槽互斥**（日期/名单/数值冲突）；互斥达阈 → **禁止合并全量 context**，改为 **仅保留一致子集**，子集仍冲突则 **弃检索走闭卷或 IDK**。 |
| **为何能降 rag_worse** | 过度检索常来自 **多高分句各说各话**，模型做并集；互斥门在 **喂模型之前** 打断「拼错名单/日期」路径。 |
| **需要什么信号** | chunk 级实体/日期抽取；pairwise 冲突图；一致子集选择（如最大一致 clique 或 top-1 锚定）。 |
| **风险** | 启发式抽取脆；真世界「多版本事实」误杀；与 N2/N3 有交集但这里是 **整题通道级**，不是解码基数——仍须 ablation 证明打的是 rag_worse 而非 set 桶整体。 |

---

### H5 · Harm-Aware Corrective-lite（伤害感知无 Web 纠检索，HAC）

| 项 | 内容 |
|----|------|
| **机制一句话** | 借鉴 Corrective **三态**，但 **Incorrect / 高伤害态：不 Web**，改为 **回退闭卷或拒答**；Correct/Ambiguous 仍滤噪或缩窗后 RAG。 |
| **为何能降 rag_worse** | 本地 G2：Incorrect 默认换源硬答不适用；rag_worse 的「误导高分」在线近似 **Incorrect+闭卷可救** 分支。 |
| **需要什么信号** | 相对阈值三态（非绝对 max）；约束违例率；可选 a0 冲突作 Incorrect 增强。 |
| **风险** | 审稿人判 Corrective 变体；三态边界若仍靠余弦，易回到 v1 失灵；须与 **闭卷回退** 硬绑定才贴 rag_worse。 |

---

### H6 · Context Ablation Stability Gate（上下文消融稳定门，CASG）

| 项 | 内容 |
|----|------|
| **机制一句话** | 对同一题比较 **top-1 短上下文** 与 **top-k 长上下文** 的短答方向；若 **加长上下文导致答案相对 top-1 大幅漂移且增量无 span 支撑** → 判定噪声注入，**采用 top-1 或闭卷**。 |
| **为何能降 rag_worse** | rag_worse 常是 **第 2–20 句噪声** 带偏；消融稳定度是「检索是否在改答案」的在线代理，不依赖 gold。 |
| **需要什么信号** | top-1 与 top-k 两次短答；答案槽 Jaccard/实体 F1；增量槽的 chunk 支撑。 |
| **风险** | 双倍（或更多）生成；multi-hop 真需多句时被误杀；算力高于 H1/H3。 |

## 4. 按「贴桶程度」排序 Top-5

| 排名 | 假说 | 贴桶理由 | 立场 |
|------|------|----------|------|
| **1** | **H1 RH-ACS+** | 25/25 闭卷已对；冲突+覆盖直接对应「绑架后回退闭卷」 | **Top-1 最挺** |
| **2** | **H2 CFG** | 显式对齐 Vanilla✓→RAG✗ 反事实；增量无支撑则拒 RAG | 强推作 **H1 对照 / 合并探针** |
| **3** | **H3 CPEP** | Pixar/set+年份类 rag_worse 多；谓词剪枝在生成前断噪声 | 推荐与 H1 **串联**（剪枝→再判 harm） |
| **4** | **H4 CMXG** | 多片段互斥是过度检索子机制；无 a0 也能滤一批 | 中等；小心与 set 幻觉叙事混淆 |
| **5** | **H5 HAC** | 叙事贴 G2，但三态信号若弱则贴桶降档 | 作 **Corrective 对照基线**，不单立主线 |

**未进 Top-5：** H6 CASG — 机制有效但 **成本/误杀 multi-hop** 高，作二期或 H1 消融。

**强烈反对作为主方法：**

- **F2 v2 / F1 v1** — 本地已负结果或刷分降级。  
- **F8 以 N2/N3 为主打 rag_worse** — 基数/双源不直接解决「闭卷已对却被绑架」；最多作 rag_worse 内 **set 子集** 插件，不能替代通道选择。  
- **F3 只调 k** — 无专属 harm 信号，历史证明不够。

## 5. 成功线：怎样才算解决了 rag_worse

在 **同一 200 典型子集**、同一裁判与生成配置下，相对 **RAG baseline**（score ≈ −0.30，accuracy ≈ 24.5%）：

### 5.1 主桶（必报，优于只看 score）

| 指标 | 定义 | 方法成功线（建议） |
|------|------|-------------------|
| **rag_worse 恢复数** | 原 25 条 `rag_worse_hallucination` 中，幻觉 → **correct** 的条数 | **≥ 8/25（32%）**；理想 ≥ 10/25 |
| **rag_worse 仍幻觉** | 25 条中仍为 hallucination | **≤ 17**（较 baseline 25 **至少减 8**） |
| **RHR** | `rag_worse_hallucination` 占比或绝对数 | 绝对数 **25 → ≤17**；占 200 比例 **12.5% → ≤8.5%** |
| **rag_worse 流转表** | 25 条逐条：baseline 结局 → 新方法结局（correct/missing/hall） | **必须交付**；可人工抽检 5 条 |

### 5.2 全局（防「只救桶、整体更差」）

| 指标 | 方法成功线 |
|------|------------|
| **accuracy** | **≥ baseline（24.5%）**，争取 ↑；**不得**为降 rag_worse 整体下降 |
| **hallucination** | **≤ baseline（54.5%）**，整体应 ↓ |
| **score** | **≥ −0.30**（不降）；最好 ↑ |
| **missing** | 可略 ↑，但 **不得** 暴涨（如 >30%）且须说明 trade-off |

### 5.3 误伤护栏（必报）

| 指标 | 定义 | 护栏 |
|------|------|------|
| **rag_helps 误杀** | 原 29 条 `rag_helps` 中 correct → wrong/missing | **≤ 3 条** |
| **both_correct 误杀** | 原 17 条双对 → 任一方变错 | **≤ 2 条** |

### 5.4 工程成功（最低档）

四指标表 + **rag_worse 25 条流转表** + **≥2 消融**（如：去 a0 / 去约束剪枝 / Astute-lite 或 HAC 对照）齐，方可称「跑通」；**仅 score↑ 而 rag_worse 条数不变不算成功**。

## 6. Top-1 一句话

**最挺 H1 RH-ACS+：用「约束覆盖 c + 闭卷探针 a0 与证据冲突」在生成前识别检索绑架并回退闭卷，专打 25 条 rag_worse；H2/H3 作同族对照或串联模块，不以 v1/v2/N1–N5 冒充 rag_worse 主解。**
