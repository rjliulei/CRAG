## 0. 一句话结论

**研究方向有眉目；论文级「创新点」还没有定稿。**

- **有眉目的是：** 做什么方向、打哪类错、用什么轻量路径验证。  
- **还没有眉目的是：** 相对现有方案，我们**多贡献了哪一条**可命名、可消融、可复现的方法主张。

创新点要等 **Step 4（RAG vs RAG+拒答，200 子集）** 出数之后才能从「候选」收成 1–2 条；现在硬编三条贡献，容易和文献撞车或实验对不上。

## 2. 为什么现在还不能叫「创新点」

创新点要能写成类似：

> 我们提出 **X**；相对 **A / B**，在设定 **C** 上得到 **D**。

我们目前更接近：

> 文献已有 **X**；我们在 **CRAG** 上做轻量验证，看有没有增量。

这是**预实验 / 方向验证**（有意义），但还不够当论文 **Contribution** 列表。

另外，定位调研已指出：单纯

```text
Retriever Score < τ → Refuse
```

在 2025–2026 文献里已偏简单。若 Step 4 只做到阈值拒答且数字平平，更难包装成方法创新。

## 3. 已有「候选创新」苗头（还不是定论）

以下是从本地错误分析 + 文献空白归纳出的**可往下挖**方向；均需 Step 4 及后续消融才能升格为正式创新点。

### 3.1 失败模式切片更细（问题定义层）

| 本地观测 | 与泛泛「降幻觉」的差异 |
|----------|------------------------|
| `false_premise` 子集几乎全 missing | 假前提会拒 ≠ 证据不足会拒 |
| `rag_worse_hallucination` 25/200 | 「检索伤对题」可单独成问题，不是只会/不会拒答 |
| `set` 幻觉重（29 条中 21 幻觉） | 集合类 partial / 多答编造，与 simple 单点事实不同 |

**若方法专门压 `rag_worse` + simple/set 的「有检索仍编」，** 而不是笼统拒答，才可能在**问题定义**上有一点差异。  
**当前：** 仅有结构统计，无对照实验 → **候选，未定稿**。

### 3.2 Partial evidence / 覆盖度（方法层）

文献空白（见定位调研 §8）：**Relevance 高但 Sufficiency 低**——例如多跳题只答一半。

与 Step 3 草案「关键声明无法在 top-k 找到支撑 → 拒答」同向；若实现从「整句相似度」升级到 **声明覆盖度 + 冲突检测**，再决策 Answer / Abstain，才接近可写的方法创新。

**当前：** Step 4 计划先做粗版支持度阈值，完整声明分解可后置 → **候选，待实现与消融**。

### 3.3 校准边界，而非一味拒答（评价层）

SemEval 2026 等案例：拒答分类器过 conservative 时，大量本可答问题也 IDK → 系统不可用。

真正研究对象是 **Risk–Coverage / score 权衡**，不是 hallucination rate 单指标。

**若我们报告：** 在 CRAG 子集上 hallucination↓ 且 score↑，并给出 coverage–accuracy 曲线或阈值敏感性，比只报「拒答率↑」更像贡献。  
**当前：** 尚无子集对照数字 → **候选，待 Step 4**。

### 3.4 场景设定（辅助，不宜单独当主创新）

- **CRAG 嘈杂 HTML + 官方 RAG 基线同协议**：实验场景清晰，可复现。  
- **中文 evidence sufficiency**（若后续转中文库）：文献相对英文少，但需换数据与语言设定。

** alone 通常撑不起创新点**，只能作为实验设定或延伸方向。

## 5. Step 4 之后：如何把「候选」收成 1–2 条创新点

### 5.1 若子集上 **明显改善**（hallucination↓，score↑，missing 略升可接受）

可尝试收成例如（择 1–2 条，勿全堆）：

1. **面向检索噪声致错的生成后门控**：在官方网页 RAG 后加支持度/一致性检查，专门降低 `rag_worse` 类失败（需报告该桶占比变化）。  
2. **声明覆盖度驱动的 selective abstention**：相对纯 prompt 拒答或纯 retriever 阈值，在 partial evidence 与 set 题上更稳（需消融：去声明分解 / 去冲突项）。  
3. **CRAG 硬例子集上的 risk–coverage 标定**：同一协议下给出 Answer–Abstain 可操作区间（需曲线或阈值表）。

### 5.2 若 **几乎不动**

- **负结果也有意义**：说明在该设定下轻量规则不够 → Day12 换备选 A（检索质量）或收束。  
- **不要**强行写创新点；改表述为「预实验否决/弱支持该路径」。

### 5.3 若 **幻觉↓ 但 score 不升或正确率大崩**

- 创新点仍无；优先调阈值 / 「仅关键声明」/ 分题型策略，再跑一轮，勿直接换题。

## 6. 当前可对外说的「研究主张」（非创新点列表）

> 在 CRAG 嘈杂网页检索下，朴素 RAG 提升正确率的同时抬高幻觉；本地错误分析表明主矛盾是「有检索仍幻觉」与「检索噪声致错」，而非假前提不会拒。我们采用文献中轻量路径——**证据支持度阈值驱动的 selective abstention**——在固定 200 典型子集上检验相对同配置 RAG 是否能在可接受 missing 上升下降低 hallucination 并提高 score；有效再考虑全量复核与更重方法，无效则据此立项或转向。
