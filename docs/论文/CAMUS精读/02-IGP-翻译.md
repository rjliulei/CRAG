# 少即是多：面向生成器对齐重排与证据选择的信息增益剪枝
### （*Less is More for RAG: Information Gain Pruning for Generator-Aligned Reranking and Evidence Selection*）

---

### 【摘要 (Abstract)】

**[段落 1]**  
检索增强生成（RAG）通过外部证据为大型语言模型（LLM）提供事实支撑，但在上下文预算受限的情况下，核心挑战在于决定应该注入哪些检索到的段落。我们表明，检索相关性指标（如 NDCG）与端到端问答质量之间的相关性很弱，甚至在多段落注入的设定下会转变为负相关——此时冗余和轻微的语义冲突会破坏生成过程的稳定性。

**[段落 2]**  
我们提出了**信息增益剪枝（Information Gain Pruning, IGP）**，这是一种易于部署的重排与剪枝模块。它利用与生成器对齐的效用信号来筛选证据，并在最终截断之前滤除低效或有害的段落，且无需更改现有的预算接口。

**[段落 3]**  
在五个开放领域问答基准测试以及多种检索器和生成器的实验中，IGP 持续提升了质量与成本之间的权衡前沿。在一个典型的多证据设定中，与仅使用检索器的基线相比，IGP 在最终输入 Token 数量减少约 76%–79% 的同时，端到端平均 F1 值获得了约 +12%–20% 的相对提升。

### 1. 引言 (Introduction)

**[背景 Background]**  
大型语言模型在开放域问答和复杂推理任务中表现出了强大的能力。然而，当输入中缺乏足够的支持证据时，LLM 仍可能生成事实错误或前后矛盾的内容。检索增强生成（RAG）通过检索外部文档并以检索到的证据为条件进行生成，有效缓解了这一问题，使回答更具可追溯性和可验证性。在实际系统中，常见的工作流是“检索 $\to$ 重排 $\to$ 截断”：系统首先召回候选段落集，然后对它们进行重排（通常根据相关性），最后在注入生成器之前，在固定预算（例如保留前 $M$ 篇段落 $\text{TOPM}$ 或 Token 预算）下进行截断。

**[动机 Motivation]**  
在已落地的 RAG 系统中，证据注入预算通常十分紧张，这使得预算约束下的证据选择成为了核心的实际关切。注入多篇证据可能会引入冗余、歧义和相互冲突的陈述，这些不仅消耗上下文预算，还会干扰生成过程，导致结论不稳定或产生不必要的过度解释。更重要的是，**检索相关性并不等同于证据对于生成的边际效用**。即使是高度相关的段落，也可能包含平行的论断、附加的前提条件或互相矛盾的细节，这会分散生成的概率分布，导致回答的稳定性下降，甚至降低准确率。

**[第一项贡献：相关性与效用的不匹配 First Contribution: Relevance–Utility Mismatch]**  
我们揭示了实用预算 RAG 中普遍存在的不匹配现象：**提高检索相关性并不能可靠地提高端到端的回答质量**。在不同的证据预算下，离线相关性指标（如 NDCG）与生成质量（F1）仅呈现微弱且不稳健的相关性，而在注入多个段落时（如 $\text{TOPM} = 5$），这种相关性甚至可能变成负相关。我们将这一现象归因于生成器层面的机制：证据的注入重塑了 Token 级别的输出分布，而冗余、无确定性结论或不一致的段落会分散概率质量，增加关键 Token 上的不确定性，从而在有限的上下文预算下破坏生成的稳定性。这促使我们将证据选择的目标从“优化相关性”转向“优化生成的证据效用”——优质证据应当让生成器在关键输出 Token 上更加收敛和稳定（即降低不确定性）。

**[第二项贡献：我们的方法 Second Contribution: Our Approach]**  
我们提出了**信息增益剪枝（IGP）**，作为“检索 $\to$ 重排 $\to$ 截断”流程中重排阶段的即插即用替代方案。IGP 从生成器的视角出发衡量证据效用：它利用单步输出分布构建归一化不确定性（NU），并将注入候选段落后不确定性的降低量定义为信息增益（IG）。随后，它根据 IG 对候选段落进行重排，并应用一个阈值在截断前剪掉负效用或微弱效用的段落，防止冗余或冲突的证据挤占有限的上下文。至关重要的是，IGP 仅替换重排阶段；下游的截断逻辑和原始预算接口（$\text{TOPM}$ 或 Token 预算）保持完全不变。此外，IGP **无需标签、无需训练、无需访问模型参数**，仅需要模型单步生成的 logits（或 Top-K 对数概率），因此与黑盒 LLM API 具有良好的兼容性。

**[第三项贡献：主要发现 Third Contribution: Main Findings]**  
在多个开放域问答基准、不同的一阶段检索器以及不同系列/尺度的生成器上，IGP 均持续提升或维持了端到端回答质量，同时削减了最终阶段的上下文成本，从而显著强化了质量与成本的帕累托前沿。值得注意的是，在典型的多证据设定中，IGP 实现了明确的“双赢”：它将平均 Token 级 F1 提升了约 +12%–20%，同时将最终阶段的平均输入 Token 减少了约 76%–79%（相较于仅检索基线）。我们的进一步分析表明，这些收益主要由**基于效用的准入控制（阈值剪枝）**驱动，而非单纯改变排序顺序；且这种优势在注入多篇证据时最为突出——因为在固定预算下，基于相关性的重排更容易引入冗余或轻度冲突的证据，放大生成器的不确定性并损害回答稳定性。

### 2. 相关工作 (Related Work)

**[引言段落]**  
本文旨在解决落地 RAG 中的实际瓶颈：在有限的上下文预算下，核心问题是哪些证据应当进入生成器的上下文，即挑选对生成最有帮助的证据，而非仅仅挑选最相关的证据。相关研究大致分为三个方向：(1) RAG 框架与检索/阅读器设计；(2) 检索-重排-截断流程中的重排与证据选择；(3) LLM 的不确定性量化与幻觉检测。IGP 处于这三者的交叉点：它利用生成器端的不确定性降低信号来重排候选并过滤负/弱效用证据。

**[2.1 检索增强生成 (RAG)]**  
RAG 为 LLM 引入了外部、可更新的非参数化知识库，使生成内容能够基于可检索证据，具备更强的可解释性。在检索端，密集检索（Dense Retrieval，如 DPR）是主流方案；REALM 等工作进一步将检索融合进预训练。在阅读器/生成器端，FiD 提出了独立编码多篇证据并在解码器中融合的范式。总体而言，大量系统遵循“高召回检索 + 强阅读器”范式。然而，在固定上下文预算下，多证据注入往往伴随冗余和冲突，单纯检索“相关”内容无法保障最终生成质量。

**[2.2 RAG 中的重排与证据选择]**  
传统流程通常采用交叉编码器（Cross-Encoder，如 BERT）或生成式重排（如 MonoT5、ColBERT）打分。近来，利用大模型做 instruction-based 重排也得到了广泛探索。然而，绝大多数重排方法仍在优化“相关性”。这导致了相关性与效用的脱节：在高相关性的段落中，依然充斥着无定论或相冲突的内容，降低了上下文对生成的边际效用。这驱动了与生成器本身深度对齐的证据选择目标。

**[2.3 LLM 的不确定性量化与幻觉检测]**  
当证据不足或不一致时，LLM 极易自信地胡说八道，因此不确定性量化（UQ）对可信系统至关重要。白盒方法利用 Token 概率、熵等信号；黑盒方法利用多采样一致性（Semantic Entropy）等检测幻觉。过去的不确定性评估主要作为事后诊断手段（如拒答或触发人工审核）。**IGP 的突破在于将不确定性从“生成后的诊断工具”前置转变为“生成前的证据准入决策信号”**。

**[2.4 本文定位 (Positioning of This Paper)]**  
IGP 在三个方面与前人工作明显区分：
1. **从相关性转向生成效用**：通过判断注入证据能否降低生成不确定性，来评估段落在受限预算下的边际效用。
2. **在重排阶段进行前置控制**：在证据塞入上下文之前直接完成效用重排和基于阈值的剪枝，提前拦截负增益段落。
3. **部署友好且兼容黑盒**：无标签、无训练、无参数访问，只需获取单步 logits/Top-K 对数概率，直接替换重排层。

### 3. 方法论 (Methodology)

#### 3.1 概述 (Overview)
* **问题设定**：标准流程为 $\text{retrieve} \to \text{rerank} \to \text{truncate}$。一阶段检索器返回候选集 $\mathcal{D} = \{d_i\}_{i=1}^N$，系统需在固定预算（如 $\text{Top-}M$ 或 Token 预算 $B$）下选择证据。
* **核心思想**：有用的证据应当使模型在固定解码协议下更加果断（decisive），即降低其在“下一个 Token 分布”上的不确定性。一个段落如果相比“无证据基线”降低了生成器的不确定性，它就是有益的。
* **IGP 流程**：替代重排阶段（$\text{retrieve} \to \text{IGP} \to \text{truncate}$）。计算无证据与注入单篇证据后的归一化不确定性（NU），两者的差值即为信息增益（IG）。按 IG 降序排列，并通过阈值 $T_p$ 进行剪枝过滤。

#### 3.2 不确定性代理指标：Top-K 归一化不确定性 (NU)
为保证指标可复现且低方差，探针协议采用 **贪婪解码（Greedy Decoding，温度为 0）**。
* 最大展开长度为 $MT$，有效长度 $T = \min\{MT, T_{\text{EOS}}\}$。
* 设第 $t$ 步的 Top-$K$ Token 集合为 $\mathcal{V}_t^{(K)}$，在这些 Token 上重新归一化概率：
  $$\tilde{p}_\phi(y_t = v \mid \hat{y}_{<t}, q; K) = \frac{\exp(z_{t,v})}{\sum_{v' \in \mathcal{V}_t^{(K)}} \exp(z_{t,v'})}$$
* 计算第 $t$ 步的归一化熵：
  $$\tilde{u}_t(q; \phi, K) = \frac{\tilde{H}_t(q; \phi, K)}{\log K} \in [0, 1]$$
* 对整个序列长度平均，得到**无条件归一化不确定性**：
  $$\widehat{NU}(q; \phi, K) = \frac{1}{T \log K} \sum_{t=1}^T \tilde{H}_t(q; \phi, K)$$
* 同理，注入单篇候选段落 $d$ 后，得到**条件归一化不确定性** $\widehat{NU}(q \mid d; \phi, K)$。

#### 3.3 信息增益 (IG)：与生成器对齐的证据效用信号
定义单篇段落的信息增益为不确定性的减少量：
$$IG(d, q; \phi, K) = \widehat{NU}(q; \phi, K) - \widehat{NU}(q \mid d; \phi, K)$$
* $IG > 0$：段落让生成变得更加确定。
* $IG < 0$：段落引入了噪声、冲突或竞争假设，分散了概率分布，产生负效用。

#### 3.4 算法实现 (Algorithm 1)
```text
输入: 问题 q; 候选文档集 D = {d_i}; 生成器 phi; 参数 K, MT; 剪枝阈值 T_p; 预算 M (可选 B)
输出: 过滤与重排列表 L; 最终注入证据集合 S

1: 计算一次无证据基线: v_0 = NU(q; phi, K)
2: 并行遍历每个候选段落 d_i (i = 1 to N):
3:     计算条件不确定性: v_i = NU(q | d_i; phi, K)
4:     计算单篇效用得分: s_i = v_0 - v_i
5: 结束循环
6: 排序: pi = argsort_descending(s)
7: L = 按 pi 排序后的候选列表
8: 剪枝过滤: L = [d for d in L if IG(d, q) >= T_p]
9: 截断接入: S = Truncate(L; M, B)  # 执行原本的 Top-M 截断
10: 返回 L, S
```

#### 3.5 关键实现细节
1. **$T_p$ 阈值的物理意义**：$T_p$ 是准入屏障。$T_p$ 越大越保守，过滤越多段落；若设为 $-\infty$，IGP 则退化为单纯的“按 IG 排序，不进行任何剪枝”。
2. **超参数选择**：$MT$ 决定了探针观察的步数，$MT$ 适中（如 32）即可让相对排序趋于稳定；$K$ 设为适中数值（如 128）即可捕获主要的竞争 Token。
3. **单篇评估与高阶交互**：IGP 采用单篇独立计算增益的方式以换取并行效率，但不显式建模集合内部的多篇重叠与互补。

### 4. 实验 (Experiments)

**[段落 1：实验总览]**  
我们在预算受限的 RAG 流程（检索 $\to$ 重排 $\to$ 截断）中，将信息增益剪枝（IGP）作为重排阶段的即插即用替代方案进行评估。我们在所有对比方法中固定底层知识库、候选数量、Prompt 提示词、解码设置以及证据预算执行器（截断逻辑：$\text{Top-}M$，可选 Token 保护门 $B$），仅改变重排/准入策略，以严格隔离并观察端到端的影响。

**[研究问题 Research Questions]**  
* **RQ1（质量–成本权衡）**：IGP 是否在不同的证据预算下都能改善端到端的质量–成本前沿？（在 4.2 节回答）
* **RQ2（机制与敏感度）**：增益主要来自重排序还是准入控制？IGP 对剪枝阈值和不确定性估计的超参数有多敏感？（在 4.3 节回答）
* **RQ3（相关性 $\neq$ 效用）**：在不同预算下，离线检索相关性指标（NDCG）预测端到端问答质量（F1）的能力究竟如何？（在 4.4.1 节回答）
* **RQ4（检索器鲁棒性）**：当更换一阶段检索器时，IGP 带来的增益是否依然稳固？（在 4.4.2 节回答）
* **RQ5（生成器鲁棒性）**：IGP 能否泛化到不同的生成模型家族和参数规模上？（在 4.4.3 节回答）

#### 4.1 实验设定 (Experimental Setup)

**[4.1.1 检索知识库 Corpus]**  
我们采用 FlashRAG 开源的维基百科检索语料库作为外部知识库。该语料库基于 2018 年 12 月 20 日的英文 Wikipedia 快照构建。清洗后，文本被切分为互不重叠的 100 词段落，总计约 2100 万个段落。除非特别说明，所有的检索、重排和截断实验均在该语料库上展开。

**[4.1.2 评测数据集 Datasets]**  
我们在五个具有互补特性的经典问答基准上进行评估：
1. **NQ**：真实用户搜索引擎查询；
2. **TriviaQA**：开放域事实类问答；
3. **PopQA**：流行文化与长尾实体知识；
4. **SQuAD**：阅读理解与抽取式问答；
5. **AmbigQA**：包含歧义的开放域问答，需要多个有效解释或答案。  
默认汇报测试集（Test）结果；若测试集未公开，则使用验证集（Dev）（因此 NQ、TriviaQA、PopQA 使用 Test 集，SQuAD、AmbigQA 使用 Dev 集）。

**[4.1.3 语言模型（生成器底座）Language Models]**  
为了验证 IGP 的黑盒可用性与模型无关性，并系统性研究模型家族与参数规模的影响，我们选取了两个主流开源指令微调模型家族：**Qwen2.5-Instruct** 和 **Llama-3.x-Instruct**。所有模型均来自 Hugging Face，推理引擎采用 vLLM，无需反向传播梯度或微调，仅导出单步 logits（或 Top-K 对数概率）用于驱动 IGP。
* **Qwen2.5 家族**：主实验使用 `Qwen2.5-7B-Instruct`；规模消融实验覆盖 0.5B、1.5B、3B、7B。
* **Llama 3.x 家族**：覆盖小型到中型规模，包括 `Llama-3.2-1B-Instruct`、`Llama-3.2-3B-Instruct`、`Llama-3.1-8B-Instruct`。

**[4.1.4 Prompt 模板与解码协议 Prompts and Decoding Protocol]**  
为了公平对比，所有实验固定 Prompt 模板：
* **(A) 最终 RAG 回答生成 Prompt**：要求模型仅根据提供的文档进行事实性作答并输出简短答案。
* **(B) NU/IG 探针 Prompt**：采用中立且简短的模板，最大限度减少 Prompt 自身对模型概率分布的干扰：
  * 无证据模板：`User: {question} \n Assistant:`
  * 单段落条件模板：`User: {question} \n Context: {context} \n Assistant:`
* **统一度量基准**：默认探针参数设为 $\text{TopK} = 128$，$MT = 32$。

**[4.1.5 基线方法 Baselines]**  
我们在统一的“检索 $\to$ 重排 $\to$ 截断”框架下，对比了代表性的检索器与重排器：
* **检索基线**：无监督稀疏检索 BM25、无监督密集检索 Contriever。
* **有监督相关性重排器**：轻量级双编码器重排 BGE、交叉编码器重排 CE（基于 MS MARCO 微调的 MiniLM）。
* **基于生成器的重排基线**：查询似然模型（QLM，即评估 $p(q \mid d)$）、二元判别式重排（YesNo，即提示模型判断文档是否相关的打分）。
* **IGP（本文方法）**：基于生成器不确定度下降的黑盒效用信号。

**[4.1.6 评价指标与成本核算 Evaluation Metrics and Cost Accounting]**  
* **回答质量**：开放域问答标准的 Token 级 Precision、Recall 和 **F1 值**（多参考答案时取最佳匹配；闭集分类用 EM）。
* **推理成本（TK）**：最终生成阶段模型的**平均输入 Token 数**（直接对应显存与计算开销）。
* **成本效益比（NTE）**：定义归一化 Token 效率 $\text{NTE} = \frac{F1_{\text{method}} / TK_{\text{method}}}{F1_{\text{baseline}} / TK_{\text{baseline}}}$，衡量“单位 Token 带来的质量改善”。
* **检索质量**：离线相关性评估采用 **NDCG@k**（用于机制分析而非优化目标）。

#### 4.2 主要实验结果：回答 RQ1 (Main Experimental Results)

**[TopM = 5：单纯重排几乎无效，准入控制才是关键驱动力]**  
在宽松的证据预算（$\text{Top-}M = 5$）下，大多数重排方法的效果与仅使用检索器的基线几乎无异。相关性重排器（+CE / +BGE）和生成式重排基线（+YesNo / +QLM）对最终上下文长度几乎没有改变，因为截断模块依然会硬塞入 5 个段落，导致 Token 成本高企且 F1 提升微弱。同样，若仅将 IG 用作排序打分而不做剪枝（+IG），端到端收益也极小。这说明：**在宽预算下，仅做“效用排序”而不做“过滤准入”是远远不够的。**

相反，一旦启用基于阈值的剪枝，收益便呈现质的飞跃：
* 设门槛为 $T_p = 0.0$ 时，输入 Token 显著下降的同时，平均 F1 明显提升；
* 采用略微保守的准入屏障 $T_p = 0.05$ 时，模型直接被推向了一个极优的运行区间（以极低的 Token 成本获得了更高的 F1）。  
这证实了核心机制：在多证据注入时，瓶颈往往不是检索召回率，而是受限预算下到底该接纳哪些证据。过滤掉弱效用和负效用段落，消除了导致生成器概率发散、结论不稳定的冗余与轻度冲突。

**[TopM = 1：基于效用的准入同时提升了准确率与效率]**  
在最严苛的预算（$\text{Top-}M = 1$）下，上下文仅允许容纳一篇段落。此时的核心问题是：挑出的这篇证据不仅要“相关”，还必须足够“果断（decisive）”，让生成器聚焦在关键答案 Token 上。相关性重排器虽能比 BM25 提升 F1，但 Token 成本没有下降。而 IGP 将效用排序与显式准入屏障结合，过滤掉了虽相关但无法定论或带来歧义的段落，在大幅压缩输入 Token 的同时显著提升了 F1。

**[帕累托视角：强化前沿面]**  
将预算扫描绘制在质量–成本平面上，传统重排器基本紧贴着检索基线移动，显示出单纯重排的乏力；而 IGP 的曲线整体向**左上方大幅平移**，这意味着它用极少的输入 Token 实现了同等乃至更高的 F1，提供了更优越的部署平衡点。

---

#### 4.3 消融实验：回答 RQ2 (Ablation Study)

**[4.3.1 剪枝阈值 $T_p$ 的敏感度]**  
在 $\text{Top-}M = 1$ 下对阈值 $T_p$ 进行扫描，结果展现出高度一致的**单峰趋势（Unimodal pattern）**，峰值普遍落在微小的正值区间（$T_p \approx 0.05$ 附近）：
* **低阈值失败于“噪声/冲突占位”**：当 $T_p$ 过低时，增益微弱甚至为负（$IG \le 0$）的段落容易浑水摸鱼通过准入，占据唯一的上下文槽位，分散了正确答案的概率质量；
* **高阈值失败于“证据缺失”**：当 $T_p$ 设得过高时，一些必要但单篇增益较小的补充性证据被误杀，上下文缺少必要事实，导致 F1 再次下滑。  
最佳平衡点在于：**在不严重牺牲召回覆盖的前提下，剔除弱/负效用证据。**

**[4.3.2 不确定度估计的敏感度：TopK 与 MaxTokens ($MT$)]**  
* **$MT$ 决定了稳定性，起主导作用**：当生成步数 $MT$ 从很小增加到中等值时，F1 显著攀升并迅速趋于平缓。因为太短的步数容易受早期 Token 局部波动的干扰；足够的步数可以平滑方差，稳定候选段落间的相对排名。
* **TopK 决定了分辨率，中等数值足矣**：极小的 $K$ 会丢弃竞争 Token 的概率质量，扭曲熵的计算；而当 $K$ 达到中等尺度（覆盖主要的候选项）后，性能便进入平原期，继续增加 $K$ 只会增加 API 传输与解析成本。
* **调优法则**：先确保 $MT$ 足够使排名稳定（如 32 步），再在成本约束内选一个适中的 $K$（如 128）。

---

#### 4.4 拓展结果与讨论：回答 RQ3–RQ5 (More Results & Discussion)

**[4.4.1 相关性指标与端到端生成质量的不匹配：回答 RQ3]**  
我们在 NQ 带有标注相关性标签的子集上（2,724 个样本）严格测试了检索排序指标（NDCG@k）与生成结果（F1）的一致性：
* **严预算（TopM = 1）**：NDCG@1 与 F1 的秩相关性极其微弱（Spearman $\rho = 0.11$）。一篇主题上相关的文章可能包含多个假设或并列陈述，无法让大模型果断下结论；
* **宽预算（TopM = 5）**：NDCG@5 与 F1 **甚至呈现出明显的负相关（Spearman $\rho = -0.54$）**！高相关性段落一旦在范围、粒度或细节上存在轻度不一致，多篇叠加就会放大不确定性。
* **直接实证**：如 Table 5 所示，$IGP(0.05)$ 在 NDCG 指标上明显低于传统的 CE/BGE 重排，但在端到端 F1 上却大幅胜出。**这直接宣告了在预算 RAG 中，“按相关性重排”这一传统范式的失效。**

**[4.4.2 检索器维度的鲁棒性：回答 RQ4]**  
将一阶段检索器从稀疏的 BM25 换为无监督密集检索 Contriever，所有定性结论完全保持一致：传统重排依然无法脱离基线，而 IGP 依旧在帕累托前沿上实现明显的左上方飞跃。这证明 IGP 的收益具有**检索器无关性**。

**[4.4.3 生成模型家族与尺度的泛化性：回答 RQ5]**  
固定一阶段检索，跨越 Qwen2.5 和 Llama 3.x 两个家族、从 0.5B 到 8B 多种尺度进行验证：
1. **小模型 + IGP 可以越级战胜不带 IGP 的大模型**：例如，搭载 IGP 的 **Qwen-1.5B** 获得的端到端 F1 超过了未搭载 IGP 的 **Qwen-7B**。这为端侧/低算力部署提供了极其强大的杠杆：通过升级证据准入策略，可以用轻量模型获得越级性能。
2. **近乎对数线性的扩展趋势**：随着模型参数增大，配备 IGP 的端到端表现稳定呈现对数线性增长，使得大模型的容量得以被充分释放，避免了被低质证据拖累。

---

#### 4.5 实验核心结论总结 (Takeaways)

1. **质量–成本双赢 (RQ1)**：IGP 大幅缩减输入 Token 成本（76%~79%），同时提高或维持了 F1；而单纯重排序收益极其有限。
2. **机制明确 (RQ2)**：收益的核心在于“准入控制（剪枝）”而非重排；剪枝阈值存在清晰且跨任务相对通用的单峰 Sweet Spot。
3. **相关性假设破裂 (RQ3)**：离线 NDCG 无法预测端到端生成质量，多证据下甚至呈负相关，证据选择必须对齐生成效用。
4. **底层解耦 (RQ4 & RQ5)**：无论前端搭配稀疏/密集检索，后端搭载何种家族/规模的大模型，IGP 的增益均稳定成立。

### 附录 A：直观案例说明（相关性 $\neq$ 证据效用）

论文在附录给出了一个极度直观的 Case（Figure 8），清晰阐明了为何高相关性文本可能具有负效用：

* **用户提问**：*“How many MB are in 1 GB?”*（1 GB 等于多少 MB？）
* **文档 A（高相关性，但有害/低效）**：
  > 内容：*“1GB=1024MB? 还是 1000MB? 这取决于操作系统和厂商... 不同系统标准存在差异。”*
  * **生成器后果**：大模型读完后陷入不确定状态，概率质量被分散，回答模棱两可：*“这取决于具体场景，有的按 1024 算，有的按 1000 算……”*（导致在严格事实 QA 评测中丢分，生成熵高，**$IG \le 0$**）。
* **文档 B（高生成效用，果断明确）**：
  > 内容：*“在十进制 SI 标准下：1GB = 1000MB；在二进制标准下：1GiB = 1024MiB。若针对日常存储标签，通常采用十进制。”*
  * **生成器后果**：大模型获得确定性指引，生成分布在精准 Token 上迅速收敛（熵骤降，**$IG > 0$**），给出明确、结构化的正确答案。

**结论**：文档 A 在传统检索器看来与 Query 极其相关，但对于生成器而言它带来了混乱；而文档 B 降低了模型决策的不确定性，具备极高的边际效用。

### 5. 结论与局限性 (Conclusion & Limitations)

#### 5.1 主要发现与总结
在预算受限的 RAG 中，检索相关性无法可靠反映生成效用，多篇注入反而会因为冗余和轻度冲突导致端到端生成质量恶化。我们提出的 IGP 通过生成器自身的不确定性下降来量化证据效用。在 5 个公开 QA 数据集上的实验证明，**基于效用的准入控制（剪枝）远比单纯的改变排序更为重要**，IGP 在减少 76%–79% 上下文 Token 消耗的同时提升了回答准确率。

#### 5.2 实践启示 (Practical Implications)
IGP 将预算 RAG 转化成了一个显式的准入控制问题。在实际落地中：
1. **轻量回退机制**：当通过 $T_p$ 的文档过少时，可配置回退规则（如回退至传统相关性截断，或根据初始 $NU(q)$ 动态判断是否启用剪枝）。
2. **监控指标**：在线服务可监控 IG 的分布漂移，从而判断检索库或 Prompt 变更是否引起了效用退化。

#### 5.3 局限性与未来工作 (Limitations and Future Work)
* **不确定度下降并不保证事实正确**：具有误导性但表述极其确定（Confident）的错误证据同样可能降低生成器的熵。因此，IGP 本质上是一个“效用信号”而非“真理校验器”，未来可结合轻量来源可靠性与一致性检验。
* **缺乏集合级交互建模（核心局限）**：IGP 是基于“单篇对比无证据”来评估效用的，没有显式建模多篇证据间的互补与冗余。未来的自然延伸方向是**集合感知选择（Set-aware selection）**，例如计算给定已选集合条件下的条件信息增益，或结合去冗余惩罚采用贪婪/次模选择算法。
