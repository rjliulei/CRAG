# 为 CRAG 做贡献 / Contributing to CRAG

我们希望让参与本项目的贡献尽可能简单、透明。 / We want to make contributing to this project as easy and transparent as possible.

## Pull Request / Pull Requests

我们欢迎你的 Pull Request。 / We actively welcome your pull requests.

1. Fork 本仓库，并从 `master` 创建你的分支。 / Fork the repo and create your branch from `master`.
2. 若添加了需要测试的代码，请补充测试。 / If you've added code that should be tested, add tests.
3. 若更改了 API，请更新文档。 / If you've changed APIs, update the documentation.
4. 确保测试套件通过。 / Ensure the test suite passes.
5. 确保代码通过 lint 检查。 / Make sure your code lints.
6. 若尚未完成，请签署贡献者许可协议（Contributor License Agreement，"CLA"）。 / If you haven't already, complete the Contributor License Agreement ("CLA").

## 贡献者许可协议（"CLA"） / Contributor License Agreement ("CLA")

为了接受你的 Pull Request，我们需要你提交 CLA。你只需为 Meta 的任意开源项目完成一次即可。 / In order to accept your pull request, we need you to submit a CLA. You only need to do this once to work on any of Meta's open source projects.

在此完成 CLA / Complete your CLA here：<https://code.facebook.com/cla>

## Issues

我们使用 GitHub Issues 跟踪公开缺陷。请确保描述清晰，并提供足够的复现步骤。 / We use GitHub issues to track public bugs. Please ensure your description is clear and has sufficient instructions to be able to reproduce the issue.

Meta 设有[漏洞赏金计划](https://bugbounty.meta.com/)，用于安全漏洞的负责任披露。此类情况请按该页面流程处理，不要提交公开 Issue。 / Meta has a [bounty program](https://bugbounty.meta.com/) for the safe disclosure of security bugs. In those cases, please go through the process outlined on that page and do not file a public issue.

## 编码风格 / Coding Style  
* 使用 4 个空格缩进，不要使用 Tab / 4 spaces for indentation rather than tabs
* 每行最长 120 个字符 / 120 character line length

参与本项目即表示你同意：你的贡献将按本源码树根目录下 LICENSE 文件中的许可进行授权。 / By contributing to this project, you agree that your contributions will be licensed under the LICENSE file in the root directory of this source tree.
